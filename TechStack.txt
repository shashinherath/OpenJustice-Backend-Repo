🧠 1. Core AI & NLP Layer	
These handle legal Q&A, translation, summarization, and reasoning.
Primary LLM
•	OpenAI GPT-4.1 / GPT-4o
(for high-accuracy legal reasoning & multilingual support)
NLP & AI Framework
•	LangChain – RAG pipeline orchestration
•	Hugging Face Transformers – additional NLP tasks
•	SentenceTransformers – for embeddings
•	OpenAI Embeddings (text-embedding-3-small or large)
________________________________________
📚 2. RAG (Retrieval-Augmented Generation) Stack
Used to reduce hallucinations & ensure legally grounded answers.
Vector Store
•	PostgreSQL + pgvector extension / Pinecone
(best for research, simple, robust, no extra systems needed)
Document Indexing
•	Chunking: LangChain RecursiveCharacterTextSplitter
•	Embeddings: SentenceTransformers or OpenAI
•	Search: Cosine similarity using pgvector
Document Storage
•	Legal PDFs stored in AWS S3 (or Azure Blob) / MiniO - local storage
________________________________________
