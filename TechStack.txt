# OpenJustice Tech Stack

🧠 1. Core AI & NLP Layer
These handle legal Q&A, translation, summarization, and reasoning.
• Primary LLM: OpenAI GPT-4o / GPT-4o-mini via `openai` SDK
• RAG Framework: LangChain + langchain-openai + langchain-community
• NLP & Embeddings: Hugging Face Transformers, SentenceTransformers
• Embeddings: OpenAI text-embedding-3-large via LangChain
• Token Counting: tiktoken
________________________________________

📚 2. RAG (Retrieval-Augmented Generation) Stack
Used to reduce hallucinations & ensure legally grounded answers.
• Vector Store: PostgreSQL + pgvector extension
• Chunking: LangChain RecursiveCharacterTextSplitter
• Search: Cosine similarity using pgvector
• Document Storage: Local filesystem (with AWS S3 / MinIO optional)
________________________________________

🔉 3. Speech & Voice Interface
For voice input/output in web app + WhatsApp.
• Speech-to-Text: OpenAI Whisper API (gpt-4o-mini-transcribe)
• Text-to-Speech: OpenAI TTS API (gpt-4o-mini-tts)
• Audio Processing: pydub, soundfile
• Frontend Voice Interface: MediaRecorder API + Web Audio API + WaveSurfer.js
________________________________________

💬 4. Messaging & Communication Layer
• WhatsApp Integration: Twilio WhatsApp API
• Web Chat Interface: FastAPI WebSocket + connection manager
• Real-time Communication (Frontend): Socket.IO Client
________________________________________

🌐 5. Backend & API Layer
• Backend Framework: FastAPI (Python 3.10+)
• Server: Uvicorn (ASGI)
• Package Manager: uv
• Validation: Pydantic 2 + pydantic-settings
• HTTP Client: httpx (async)
• Testing: Pytest, pytest-asyncio, pytest-cov, pytest-mock
• Code Quality: Black, Flake8, mypy, isort
________________________________________

🖥️ 6. Frontend Technologies
• Framework: React 19
• Language: TypeScript ~5.9
• Build Tool: Vite 7
• Styling: TailwindCSS 4
• State Management: Zustand 5 (with `persist` middleware) + React Context
• Routing: React Router DOM 7
• Data Fetching: Axios (with interceptors)
• UI Components: Radix UI primitives (Dialog, Dropdown Menu, Tabs, Tooltip)
• Styling Utilities: class-variance-authority (CVA), clsx, tailwind-merge
• Icons: Lucide React
• Internationalization: i18next + react-i18next + i18next-browser-languagedetector
• Testing: Vitest + React Testing Library + jsdom
• Linting: ESLint 9 + typescript-eslint
________________________________________

🗄️ 7. Databases & Storage
• Primary Database: PostgreSQL 15+
• Vector Extension: pgvector
• ORM: SQLAlchemy 2+ (async via asyncpg)
• Migrations: Alembic (async-aware)
• Object Storage: Local filesystem (with AWS S3 / MinIO optional)
________________________________________

🔐 8. Security Stack
• Authentication: JWT (python-jose) + bcrypt (passlib)
• HTTP-only Cookie Delivery
• Prompt Injection Detection (PromptSecurityValidator)
• Full telemetry logging (PgLLMLogRepository, PgAuditLogRepository)
________________________________________

🏛️ System Architecture Summary (High-Level)
User (React Web / Twilio WhatsApp / Voice)
        ↓
FastAPI Backend (Controllers & WebSocket)
        ↓
RAG Engine & Services (LangChain + OpenAI)
        ↓
Database (PostgreSQL + pgvector) & Local Storage
