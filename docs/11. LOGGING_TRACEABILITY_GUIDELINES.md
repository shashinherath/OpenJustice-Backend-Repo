# 🔟 Logging, Auditing & Traceability Guidelines

## 📋 Purpose

Enable **research evaluation** and **legal accountability** through comprehensive logging. Track AI decisions, retrieval processes, and user interactions for analysis, debugging, and compliance.

---

## 🎯 Core Principles

1. **Trace Everything AI** - Log all AI decisions
2. **Correlate Requests** - Link related operations
3. **Protect Privacy** - Never log PII/passwords
4. **Structure Logs** - JSON for machine parsing
5. **Level Appropriately** - Research vs production

---

## 🚫 What NOT to Log

Never log sensitive data including passwords, API keys, JWT tokens, credit card numbers, or personally identifiable information (PII). Logging sensitive data creates security vulnerabilities and compliance violations. Use automatic redaction or exclusion rules to prevent accidental logging of sensitive fields.

### Sensitive Data Exclusions

```python
# app/core/log_sanitizer.py

class LogSanitizer:
    """Sanitize logs to prevent PII/sensitive data leakage"""

    # Patterns to redact
    SENSITIVE_PATTERNS = {
        "password": r"password[\"']?\s*[:=]\s*[\"']?([^\"',\s]+)",
        "jwt": r"Bearer\s+([A-Za-z0-9-_=]+\.[A-Za-z0-9-_=]+\.?[A-Za-z0-9-_.+/=]*)",
        "api_key": r"api[_-]?key[\"']?\s*[:=]\s*[\"']?([^\"',\s]+)",
        "credit_card": r"\b\d{4}[-\s]?\d{4}[-\s]?\d{4}[-\s]?\d{4}\b",
        "email": r"\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b"
    }

    @staticmethod
    def sanitize_dict(data: dict) -> dict:
        """Recursively sanitize dictionary"""

        sanitized = {}

        for key, value in data.items():
            # Check if key is sensitive
            if any(sensitive in key.lower() for sensitive in ["password", "secret", "key", "token"]):
                sanitized[key] = "***REDACTED***"
            elif isinstance(value, dict):
                sanitized[key] = LogSanitizer.sanitize_dict(value)
            elif isinstance(value, str):
                sanitized[key] = LogSanitizer.sanitize_string(value)
            else:
                sanitized[key] = value

        return sanitized

    @staticmethod
    def sanitize_string(text: str) -> str:
        """Sanitize string for sensitive patterns"""

        sanitized = text

        for pattern_name, pattern in LogSanitizer.SENSITIVE_PATTERNS.items():
            sanitized = re.sub(pattern, f"[{pattern_name.upper()}_REDACTED]", sanitized)

        return sanitized

# Example usage
logger.info(
    "Request received",
    extra=LogSanitizer.sanitize_dict(request_data)
)
```

### Exclusion Rules

**NEVER log:**

- Raw passwords
- JWT tokens
- API keys
- Credit card numbers
- Full email addresses (hash or mask)
- Phone numbers (mask last 6 digits)
- NIC numbers (mask middle 7 digits)
- Full names (use user_id instead)

**ALWAYS sanitize:**

- Request bodies
- Response bodies
- Headers (redact Authorization)
- Query parameters

## 🤖 AI Decision Logging

Log every AI decision with complete context for reproducibility and debugging. Record model version, prompt version, inputs, outputs, confidence scores, and timing. This audit trail enables researchers to analyze model behavior, reproduce issues, and evaluate system performance over time.

### LLM Request/Response Logging

```python
# app/services/llm/logging.py
from datetime import datetime
from uuid import uuid4

class LLMLogger:
    """Log LLM interactions for research"""

    @staticmethod
    async def log_llm_request(
        correlation_id: str,
        prompt: str,
        model: str,
        temperature: float,
        max_tokens: int,
        user_id: Optional[int] = None
    ):
        """Log LLM request"""

        log_entry = {
            "event": "llm_request",
            "correlation_id": correlation_id,
            "timestamp": datetime.utcnow().isoformat(),
            "model": model,
            "temperature": temperature,
            "max_tokens": max_tokens,
            "prompt_length": len(prompt),
            "prompt_hash": hashlib.sha256(prompt.encode()).hexdigest()[:16],
            "user_id": user_id
        }

        logger.info("LLM request", extra=log_entry)

        # Store full prompt in research database (not in logs)
        if settings.RESEARCH_MODE:
            await store_research_prompt(correlation_id, prompt)

    @staticmethod
    async def log_llm_response(
        correlation_id: str,
        response: str,
        usage: dict,
        latency_ms: int,
        provider: str
    ):
        """Log LLM response"""

        log_entry = {
            "event": "llm_response",
            "correlation_id": correlation_id,
            "timestamp": datetime.utcnow().isoformat(),
            "provider": provider,
            "response_length": len(response),
            "tokens_used": usage.get("total_tokens", 0),
            "prompt_tokens": usage.get("prompt_tokens", 0),
            "completion_tokens": usage.get("completion_tokens", 0),
            "latency_ms": latency_ms
        }

        logger.info("LLM response", extra=log_entry)

        # Store full response in research database
        if settings.RESEARCH_MODE:
            await store_research_response(correlation_id, response)

    @staticmethod
    async def log_llm_error(
        correlation_id: str,
        error: Exception,
        provider: str
    ):
        """Log LLM error"""

        log_entry = {
            "event": "llm_error",
            "correlation_id": correlation_id,
            "timestamp": datetime.utcnow().isoformat(),
            "provider": provider,
            "error_type": type(error).__name__,
            "error_message": str(error)
        }

        logger.error("LLM error", extra=log_entry)

llm_logger = LLMLogger()
```

### Prompt Version Tracking

Track which prompt version was used for each request to enable reproducibility and A/B testing analysis. Store prompt version metadata alongside request logs so you can correlate prompt changes with output quality.

```python
async def generate_with_logging(
    prompt_template: str,
    prompt_version: str,
    variables: dict,
    user_id: int
) -> str:
    """Generate response with comprehensive logging"""

    correlation_id = str(uuid4())

    # Render prompt
    prompt = prompt_template.format(**variables)

    # Log request
    await llm_logger.log_llm_request(
        correlation_id=correlation_id,
        prompt=prompt,
        model="gpt-4o",
        temperature=0.7,
        max_tokens=500,
        user_id=user_id
    )

    # Additional metadata
    logger.info(
        "Prompt generation",
        extra={
            "correlation_id": correlation_id,
            "prompt_version": prompt_version,
            "template_name": get_template_name(prompt_template),
            "variables": list(variables.keys())  # Don't log values
        }
    )

    start_time = datetime.utcnow()

    try:
        # Generate
        response = await llm_service.generate(prompt)

        # Calculate latency
        latency_ms = int((datetime.utcnow() - start_time).total_seconds() * 1000)

        # Log response
        await llm_logger.log_llm_response(
            correlation_id=correlation_id,
            response=response,
            usage=response.get("usage", {}),
            latency_ms=latency_ms,
            provider="openai"
        )

        return response

    except Exception as e:
        # Log error
        await llm_logger.log_llm_error(
            correlation_id=correlation_id,
            error=e,
            provider="openai"
        )
        raise
```

## 🔍 Retrieval & Citation Logging

Log the entire retrieval pipeline including queries, retrieved documents, similarity scores, and final citations. This enables debugging retrieval issues, evaluating retrieval quality, and verifying citation accuracy. Track which documents were retrieved but not cited to identify potential issues.

### Retrieval Process Logging

```python
# app/services/rag/retrieval_logger.py

class RetrievalLogger:
    """Log retrieval operations for analysis"""

    @staticmethod
    async def log_retrieval_request(
        correlation_id: str,
        query: str,
        language: str,
        top_k: int
    ):
        """Log retrieval request"""

        log_entry = {
            "event": "retrieval_request",
            "correlation_id": correlation_id,
            "timestamp": datetime.utcnow().isoformat(),
            "query_length": len(query),
            "query_hash": hashlib.sha256(query.encode()).hexdigest()[:16],
            "language": language,
            "top_k": top_k
        }

        logger.info("Retrieval request", extra=log_entry)

    @staticmethod
    async def log_retrieval_results(
        correlation_id: str,
        results: List[dict],
        latency_ms: int
    ):
        """Log retrieval results"""

        # Extract confidence scores
        scores = [r["score"] for r in results]

        log_entry = {
            "event": "retrieval_results",
            "correlation_id": correlation_id,
            "timestamp": datetime.utcnow().isoformat(),
            "result_count": len(results),
            "top_score": max(scores) if scores else 0.0,
            "avg_score": sum(scores) / len(scores) if scores else 0.0,
            "min_score": min(scores) if scores else 0.0,
            "latency_ms": latency_ms,
            "document_ids": [r["doc_id"] for r in results]
        }

        logger.info("Retrieval results", extra=log_entry)

    @staticmethod
    async def log_no_results(
        correlation_id: str,
        query: str,
        threshold: float
    ):
        """Log when no results meet threshold"""

        log_entry = {
            "event": "retrieval_no_results",
            "correlation_id": correlation_id,
            "timestamp": datetime.utcnow().isoformat(),
            "query_hash": hashlib.sha256(query.encode()).hexdigest()[:16],
            "threshold": threshold
        }

        logger.warning("No retrieval results", extra=log_entry)

retrieval_logger = RetrievalLogger()
```

## 🔗 Request Correlation IDs

Assign unique correlation IDs to each request and propagate them through all services and log entries. This enables tracing a user request across multiple services, database queries, and external API calls. Correlation IDs are essential for debugging distributed systems and understanding end-to-end request flow.

### Correlation ID Implementation

```python
# app/middleware/correlation.py
from contextvars import ContextVar

# Context variable for correlation ID
correlation_id_var: ContextVar[str] = ContextVar("correlation_id", default=None)

class CorrelationMiddleware(BaseHTTPMiddleware):
    """Add correlation ID to all requests"""

    async def dispatch(self, request: Request, call_next):
        # Generate or extract correlation ID
        correlation_id = request.headers.get("X-Correlation-ID") or str(uuid4())

        # Set in context
        correlation_id_var.set(correlation_id)

        # Add to response headers
        response = await call_next(request)
        response.headers["X-Correlation-ID"] = correlation_id

        return response

# Add middleware
app.add_middleware(CorrelationMiddleware)
```

### Correlation-Aware Logger

Build a context-aware logger that automatically includes correlation IDs in all log entries. Store correlation ID in request context so all downstream code can access it without explicit parameter passing.

```python
# app/core/logger.py
import logging
from pythonjsonlogger import jsonlogger

class CorrelationLoggerAdapter(logging.LoggerAdapter):
    """Logger that includes correlation ID"""

    def process(self, msg, kwargs):
        # Add correlation ID from context
        correlation_id = correlation_id_var.get()

        if "extra" not in kwargs:
            kwargs["extra"] = {}

        kwargs["extra"]["correlation_id"] = correlation_id

        return msg, kwargs

# Configure JSON logging
log_handler = logging.StreamHandler()
formatter = jsonlogger.JsonFormatter(
    "%(timestamp)s %(level)s %(name)s %(correlation_id)s %(message)s"
)
log_handler.setFormatter(formatter)

# Create logger
base_logger = logging.getLogger("openjustice")
base_logger.addHandler(log_handler)
base_logger.setLevel(logging.INFO)

# Export correlation-aware logger
logger = CorrelationLoggerAdapter(base_logger, {})
```

### Cross-Service Correlation

Propagate correlation IDs across service boundaries by including them in HTTP headers or message metadata. This enables distributed tracing across microservices or external API calls.

```python
async def call_external_service(url: str, data: dict) -> dict:
```

## 📊 Logging Levels (Research vs Demo)

Adjust logging verbosity based on environment. Research/development environments need verbose logging for debugging and analysis, while production/demo environments should log less to reduce noise and costs. Use environment variables to control logging levels dynamically.

### Environment-Based Logging

```python
# app/config.py

class LoggingConfig(BaseSettings):
    """Logging configuration"""

    # Environment
    ENVIRONMENT: str = "development"  # development | research | demo | production

    # Logging levels
    LOG_LEVEL: str = "INFO"

    # Feature flags
    LOG_FULL_PROMPTS: bool = False
    LOG_FULL_RESPONSES: bool = False
    LOG_REQUEST_BODIES: bool = False
    LOG_RESPONSE_BODIES: bool = False

    @property
    def is_research_mode(self) -> bool:
        return self.ENVIRONMENT == "research"

    @property
    def is_demo_mode(self) -> bool:
        return self.ENVIRONMENT == "demo"

    def get_log_level(self, logger_name: str) -> str:
        """Get log level for specific logger"""

        # Research mode: verbose logging
        if self.is_research_mode:
            return "DEBUG"

        # Demo mode: minimal logging
        if self.is_demo_mode:
            return "WARNING"

        # Production: INFO
        return self.LOG_LEVEL

logging_config = LoggingConfig()
```

### Conditional Logging

Implement conditional logging that changes behavior based on environment configuration. Enable detailed AI tracing in research mode but use minimal logging in production to optimize performance.

```python
async def process_with_conditional_logging(query: str, user_id: int):
    """Process with environment-aware logging"""

    # Always log basic info
    logger.info(
        "Query processing started",
        extra={
            "user_id": user_id,
            "query_length": len(query)
        }

        logger.debug(
            "Full query content",
            extra={
                "query": query,
                "user_id": user_id
            }
        )

    # Process query
    response = await query_service.process(query)

    # Research mode: log full response
    if logging_config.is_research_mode:
        logger.debug(
            "Full response content",
            extra={
                "response": response,
                "user_id": user_id
            }
        )

    # Always log result status
    logger.info(
        "Query processing completed",
        extra={
            "user_id": user_id,
            "response_length": len(response)
        }
    )

    return response
```

## 📝 Audit Trail Structure

Maintain a structured audit trail for all user actions, AI decisions, and system changes. Use a consistent schema with standard fields (timestamp, user ID, action type, resource affected). Store audit logs separately from application logs with longer retention and stricter access controls.

### Audit Event Schema

```python
# app/models/audit.py
from sqlalchemy import Column, Integer, String, JSON, DateTime, Enum
from enum import Enum as PyEnum

class AuditEventType(PyEnum):
    """Audit event types"""
    USER_LOGIN = "user_login"
    USER_LOGOUT = "user_logout"
    QUERY_SUBMITTED = "query_submitted"
    RESPONSE_GENERATED = "response_generated"
    DOCUMENT_UPLOADED = "document_uploaded"
    DOCUMENT_DELETED = "document_deleted"
    SETTINGS_CHANGED = "settings_changed"
    ADMIN_ACTION = "admin_action"

class AuditLog(Base):
    """Audit log table"""

    __tablename__ = "audit_logs"

    id = Column(Integer, primary_key=True)

    # Event identification
    event_type = Column(Enum(AuditEventType), nullable=False, index=True)
    correlation_id = Column(String(36), nullable=False, index=True)

    # User identification
    user_id = Column(Integer, nullable=True, index=True)
    session_id = Column(String(64), nullable=True)

    # Event details
    resource_type = Column(String(50), nullable=True)  # e.g., "document", "query"
    resource_id = Column(String(100), nullable=True)
    action = Column(String(50), nullable=False)  # e.g., "create", "read", "update", "delete"

    # Metadata
    metadata = Column(JSON, nullable=True)

    # Context
    ip_address = Column(String(45), nullable=True)
    user_agent = Column(String(500), nullable=True)

    # Timing
    timestamp = Column(DateTime, nullable=False, index=True)

    # Result
    success = Column(Boolean, nullable=False)
    error_message = Column(String(500), nullable=True)
```

### Audit Logger

Implement a dedicated audit logger that writes to a separate audit log table or file. Ensure audit logs are immutable and include cryptographic hashes for tamper detection in high-security scenarios.

```python
# app/services/audit/logger.py

class AuditLogger:
    """Create structured audit trail"""

    @staticmethod
    async def log_event(
        event_type: AuditEventType,
        user_id: Optional[int],
        action: str,
        resource_type: Optional[str] = None,
        resource_id: Optional[str] = None,
        metadata: Optional[dict] = None,
        success: bool = True,
        error_message: Optional[str] = None,
        request: Optional[Request] = None
    ):
        """Log audit event"""

        # Get correlation ID
        correlation_id = correlation_id_var.get() or str(uuid4())

        # Extract request context
        ip_address = None
        user_agent = None
        session_id = None

        if request:
            ip_address = request.client.host
            user_agent = request.headers.get("User-Agent")
            session_id = request.cookies.get("session_id")

        # Create audit log entry
        audit_entry = AuditLog(
            event_type=event_type,
            correlation_id=correlation_id,
            user_id=user_id,
            session_id=session_id,
            resource_type=resource_type,
            resource_id=resource_id,
            action=action,
            metadata=LogSanitizer.sanitize_dict(metadata or {}),
            ip_address=ip_address,
            user_agent=user_agent,
            timestamp=datetime.utcnow(),
            success=success,
            error_message=error_message
        )

        # Store in database
        async with get_db_session() as session:
            session.add(audit_entry)
            await session.commit()

        # Also log to structured logger
        logger.info(
            "Audit event",
            extra={
                "event_type": event_type.value,
                "correlation_id": correlation_id,
                "user_id": user_id,
                "action": action,
                "resource_type": resource_type,
                "resource_id": resource_id,
                "success": success
            }
        )

audit_logger = AuditLogger()
```

## 🔬 Research-Specific Logging

Capture detailed data for research and evaluation purposes including user interactions, model performance metrics, and system behavior patterns. Structure research logs for easy analysis and export. Balance research needs with user privacy by anonymizing or aggregating sensitive data.

### Research Data Collection

```python
# app/research/data_collector.py

class ResearchDataCollector:
    """Collect detailed data for research evaluation"""

    @staticmethod
    async def log_research_interaction(
        user_id: int,
        query: str,
        response: str,
        retrieved_docs: List[dict],
        citations: List[dict],
        model_config: dict,
        latency_ms: int
    ):
        """Log complete interaction for research"""

        if not logging_config.is_research_mode:
            return  # Only in research mode

        correlation_id = correlation_id_var.get()

        # Store in dedicated research database
        research_data = {
            "correlation_id": correlation_id,
            "timestamp": datetime.utcnow().isoformat(),
            "user_id": user_id,

            # Input
            "query": query,
            "query_length": len(query),
            "query_language": detect_language(query),

            # Retrieval
            "retrieved_docs": [
                {
                    "doc_id": doc["id"],
                    "score": doc["score"],
                    "metadata": doc["metadata"]
                }
                for doc in retrieved_docs
            ],
            "retrieval_count": len(retrieved_docs),
            "avg_retrieval_score": sum(d["score"] for d in retrieved_docs) / len(retrieved_docs),

            # Generation
            "response": response,
            "response_length": len(response),
            "citations": citations,
            "citation_count": len(citations),

            # Model
            "model": model_config["model"],
            "temperature": model_config["temperature"],
            "max_tokens": model_config["max_tokens"],

            # Performance
            "latency_ms": latency_ms
        }

        await store_research_data(research_data)

        logger.info(
            "Research data collected",
            extra={
                "correlation_id": correlation_id,
                "user_id": user_id
            }
        )

research_collector = ResearchDataCollector()
```

## 🚨 Common Mistakes to Avoid

❌ **Logging PII**

```python
# BAD
logger.info(f"User {user.email} logged in")  # Logs email!
logger.info(f"Password: {password}")  # NEVER!
```

✅ **Use user IDs**

```python
# GOOD
logger.info(f"User {user.id} logged in")
```

❌ **Missing correlation IDs**

```python
# BAD
logger.info("LLM request")  # Can't link to response!
```

✅ **Always correlate**

```python
# GOOD
logger.info("LLM request", extra={"correlation_id": correlation_id})
```

❌ **Unstructured logs**

```python
# BAD
logger.info(f"Query: {query}, Result: {result}")  # Hard to parse
```

✅ **Use structured logging**

```python
# GOOD
logger.info("Query processed", extra={"query_length": len(query), "result_count": len(result)})
```
