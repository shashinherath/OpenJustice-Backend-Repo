# AI & LLM Usage Guidelines

## 📋 Purpose

Control how Large Language Models (LLMs) are used to ensure **accuracy**, **ethics**, **reproducibility**, and **cost efficiency** in the OpenJustice legal assistance platform.

---

## 🎯 Core Principles

1. **Centralized Access** — All LLM calls go through `LLMService` and `ILLMClient`
2. **Version Control** — Track model versions and prompt changes via `PromptRegistry`
3. **Anti-Hallucination** — Enforce citation requirements in system prompts
4. **Ethical AI** — Neutral, unbiased responses validated by `PromptSecurityValidator`
5. **Cost Control** — Monitor token usage via `LLMRequest` telemetry logging

---

## 🏗️ Architecture Rules

All LLM interactions flow through the Clean Architecture layers. The domain defines an abstract `ILLMClient` port, the infrastructure layer implements it with `OpenAIClient`, and the application layer orchestrates through `LLMService`. Never make direct OpenAI API calls from controllers.

### The LLM Client Interface (Domain Port)

The domain layer defines a contract that decouples business logic from any specific LLM provider:

```python
# app/domain/interfaces/llm_client.py
from abc import ABC, abstractmethod
from typing import AsyncGenerator, Dict, List, Any


class ILLMClient(ABC):
    """Interface for connecting to external Language Models."""

    @abstractmethod
    async def generate_response(
        self, messages: List[Dict[str, Any]], temperature: float = None, max_tokens: int = None
    ) -> str:
        """Generate a complete synchronous text response."""
        pass

    @abstractmethod
    async def stream_response(
        self, messages: List[Dict[str, Any]], temperature: float = None, max_tokens: int = None
    ) -> AsyncGenerator[str, None]:
        """Stream back pieces of text as they are generated."""
        pass
```

### The OpenAI Client (Infrastructure Adapter)

The infrastructure layer implements `ILLMClient` using the OpenAI SDK. This is the **only** place where `openai` is imported:

```python
# app/infrastructure/external/openai_client.py
from typing import AsyncGenerator, Dict, List, Any
from openai import AsyncOpenAI
from app.config import settings
from app.domain.interfaces.llm_client import ILLMClient


class OpenAIClient(ILLMClient):
    """Concrete implementation of ILLMClient using OpenAI endpoints."""

    def __init__(self):
        self.client = AsyncOpenAI(api_key=settings.OPENAI_API_KEY)
        self.model = settings.OPENAI_MODEL

    async def generate_response(self, messages: List[Dict[str, Any]], **kwargs) -> str:
        response = await self.client.chat.completions.create(
            model=self.model, messages=messages, stream=False, **kwargs
        )
        return response.choices[0].message.content or ""

    async def stream_response(self, messages: List[Dict[str, Any]], **kwargs) -> AsyncGenerator[str, None]:
        stream = await self.client.chat.completions.create(
            model=self.model, messages=messages, stream=True, **kwargs
        )
        async for chunk in stream:
            content = chunk.choices[0].delta.content
            if content is not None:
                yield content
```

### ❌ DON'T: Direct API Calls from Controllers

```python
# ❌ WRONG: Direct OpenAI call in controller
@router.post("/chat")
async def chat_endpoint(message: str):
    client = OpenAI(api_key="sk-...")       # NEVER import openai here
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": message}]
    )
    return response
```

## 📝 Prompt Versioning & Template Management

Prompts are stored centrally in `app/application/prompts/` and managed through the `PromptRegistry` class. Never hardcode prompts in services or controllers.

### Prompt Registry

The `PromptRegistry` stores versioned templates and supports automatic "latest" resolution:

```python
# app/application/prompts/__init__.py
class PromptRegistry:
    """Manage all prompt templates across the platform."""

    _templates: Dict[str, Dict[str, str]] = {}

    @classmethod
    def register(cls, name: str, version: str, template: str) -> None:
        """Register a new version of a prompt template."""
        if name not in cls._templates:
            cls._templates[name] = {}
        cls._templates[name][version] = template

    @classmethod
    def get(cls, name: str, version: str = "latest") -> str:
        """Get a specific prompt template by name and version."""
        if name not in cls._templates:
            raise ValueError(f"Unknown prompt template: {name}")

        templates = cls._templates[name]

        if version == "latest":
            version = max(templates.keys())

        if version not in templates:
            raise ValueError(f"Version {version} not found for {name}")

        return templates[version]

    @classmethod
    def list_versions(cls, name: str) -> list[str]:
        """List all registered versions of a specific template."""
        return list(cls._templates.get(name, {}).keys())
```

### Registering Prompt Templates

Templates are registered in `app/application/prompts/multilingual.py` at import time:

```python
# app/application/prompts/multilingual.py
from app.application.prompts import PromptRegistry

LEGAL_ASSISTANT_EN_V1 = """You are OpenJustice, a highly capable AI legal assistant...

MANDATORY RULES:
1. Only answer questions about Sri Lankan law.
2. Provide clear, well-structured answers.
3. If you don't know the answer, admit it.
4. IMPORTANT: Cite the exact source Act and Section using [Source: Act Name, Section Number]
...

CONTEXT:
{context}
"""

# Register all language templates
PromptRegistry.register("legal_assistant_english", "v1", LEGAL_ASSISTANT_EN_V1)
PromptRegistry.register("legal_assistant_sinhala", "v1", LEGAL_ASSISTANT_SI_V1)
PromptRegistry.register("legal_assistant_tamil", "v1", LEGAL_ASSISTANT_TA_V1)
```

### Using Versioned Prompts in Services

The `MultilingualPromptBuilder` fetches and formats templates by language code:

```python
# app/application/prompts/multilingual.py
class MultilingualPromptBuilder:
    """Build language-specific system prompts securely."""

    LANGUAGE_MAP = {
        "en": "legal_assistant_english",
        "si": "legal_assistant_sinhala",
        "ta": "legal_assistant_tamil",
    }

    @classmethod
    def build_system_prompt(cls, language_code: str, context: str) -> str:
        """Fetch and build the correct prompt version."""
        template_name = cls.LANGUAGE_MAP.get(language_code, "legal_assistant_english")
        template = PromptRegistry.get(template_name, "latest")
        return template.format(context=context)
```

## 📊 Model Version Logging

Every LLM request is logged to the `llm_requests` table with full metadata for reproducibility, debugging, and cost tracking.

### LLM Request Model

```python
# app/infrastructure/models/llm_request.py
class LLMRequest(Base):
    """Records every LLM API call for research and cost traceability."""
    __tablename__ = "llm_requests"

    id: Mapped[uuid.UUID] = mapped_column(PGUUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    correlation_id: Mapped[Optional[uuid.UUID]] = mapped_column(PGUUID(as_uuid=True), nullable=True)
    user_id: Mapped[Optional[uuid.UUID]] = mapped_column(PGUUID(as_uuid=True), ForeignKey("users.id"))

    query: Mapped[Optional[str]] = mapped_column(Text, nullable=True)
    context: Mapped[Optional[str]] = mapped_column(Text, nullable=True)

    model_name: Mapped[Optional[str]] = mapped_column(String(100), nullable=True)
    prompt_version: Mapped[Optional[str]] = mapped_column(String(50), nullable=True)

    temperature: Mapped[Optional[float]] = mapped_column(Float, nullable=True)
    max_tokens: Mapped[Optional[int]] = mapped_column(Integer, nullable=True)

    prompt_tokens: Mapped[Optional[int]] = mapped_column(Integer, nullable=True)
    completion_tokens: Mapped[Optional[int]] = mapped_column(Integer, nullable=True)
    total_tokens: Mapped[Optional[int]] = mapped_column(Integer, nullable=True)

    latency_ms: Mapped[Optional[int]] = mapped_column(Integer, nullable=True)
    status: Mapped[Optional[str]] = mapped_column(String(20), nullable=True)
    error_message: Mapped[Optional[str]] = mapped_column(Text, nullable=True)

    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())

    # Relationships
    user: Mapped[Optional["User"]] = relationship("User", back_populates="llm_requests")
    responses: Mapped[list["LLMResponse"]] = relationship("LLMResponse", back_populates="llm_request")
```

### Telemetry Logging in LLMService

The `LLMService` uses `tiktoken` for precise token counting and logs every interaction:

```python
# app/application/services/llm_service.py (simplified)
import tiktoken
import time

class LLMService:
    def _count_tokens(self, text: str) -> int:
        """Count tokens using tiktoken for the active model."""
        encoding = tiktoken.encoding_for_model(self.client.model)
        return len(encoding.encode(text))

    async def _log_llm_telemetry(self, user_id, query, context, model_name,
                                  prompt_tokens, completion_tokens, total_tokens,
                                  latency_ms, status, error_message=None):
        """Log LLM request telemetry to database."""
        llm_request = LLMRequest(
            user_id=user_id,
            query=query, context=context,
            model_name=model_name,
            prompt_tokens=prompt_tokens,
            completion_tokens=completion_tokens,
            total_tokens=total_tokens,
            latency_ms=latency_ms,
            status=status, error_message=error_message,
        )
        await self.llm_log_repository.save(llm_request)
```

## 🛡️ Semantic Cache

Before calling the LLM, the `LLMService` checks a pgvector-based semantic cache. If a semantically similar query (cosine similarity ≥ 95%) has been answered before, the cached response is returned instantly—saving tokens and latency.

### SemanticCache Model

```python
# app/infrastructure/models/semantic_cache.py
class SemanticCache(Base):
    """Semantic cache mapping previously asked queries to generated responses.
    Uses pgvector for semantic search (e.g. 95% similarity match)."""

    __tablename__ = "semantic_caches"

    id = Column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    query_text = Column(String, nullable=False)
    query_embedding = Column(Vector(3072), nullable=False)  # text-embedding-3-large
    response_text = Column(String, nullable=False)
    created_at = Column(DateTime, default=datetime.utcnow, nullable=False)
```

### Cache Flow in LLMService

```
User query → Embed query → pgvector cosine search → similarity ≥ 0.95?
    YES → Return cached response (no LLM call)
    NO  → Call LLM → Save response to cache → Return
```

The cache threshold is configurable via `settings.CACHE_SIMILARITY_THRESHOLD` (default: `0.95`).

## 📋 Checklist: Before Using LLM

✅ **Architecture**

- [ ] Call goes through `LLMService` → `ILLMClient` → `OpenAIClient`
- [ ] Using versioned prompt templates from `app/application/prompts/`
- [ ] Telemetry logging enabled via `LLMRequest` model

✅ **Safety**

- [ ] Prompt injection check via `PromptSecurityValidator.is_safe()`
- [ ] Input sanitized via `PromptSecurityValidator.sanitize()`
- [ ] Neutral language validated via `PromptSecurityValidator.validate_neutral_language()`

✅ **Cost Control**

- [ ] Semantic cache checked before LLM call
- [ ] Token counting via `tiktoken`
- [ ] Token usage logged to `llm_requests` table

✅ **Reproducibility**

- [ ] Request logged to database with correlation ID
- [ ] Model name and prompt version recorded
- [ ] Temperature and max_tokens logged
- [ ] Latency tracked in milliseconds

## 🚨 Common Mistakes to Avoid

❌ **Direct OpenAI imports in controllers**

```python
# BAD — only app/infrastructure/external/openai_client.py should import openai
from openai import OpenAI
```

❌ **Hardcoded prompts**

```python
# BAD — use PromptRegistry.get() instead
system_message = "You are a legal assistant..."
```

❌ **Missing error handling**

```python
# BAD — always wrap LLM calls in try/except with telemetry logging
response = await client.chat.completions.create(...)
```

❌ **Skipping the semantic cache**

```python
# BAD — always check cache before calling the LLM
response = await self.client.generate_response(messages)
```
