# 3️⃣ RAG Pipeline Coding Guidelines

## 📋 Purpose

Enforce strict **separation of retrieval and generation** logic for the OpenJustice RAG (Retrieval-Augmented Generation) system. Ensure accuracy, reproducibility, and maintainability.

---

## 🎯 Core Principles

1. **Separation of Concerns** - Retriever ≠ Generator
2. **Deterministic Retrieval** - Same query → Same documents
3. **Citation Traceability** - Every fact → Source document
4. **Confidence Scoring** - Measure retrieval quality
5. **Chunking Consistency** - Uniform document segmentation

---

## 🏗️ RAG Architecture

```
User Query
    ↓
[1. Query Processing] → Normalize, sanitize, detect language
    ↓
[2. Retrieval Service] → Fetch relevant document chunks
    ↓
[3. Context Assembly] → Format retrieved chunks
    ↓
[4. Generation Service] → Generate answer with LLM
    ↓
[5. Citation Validation] → Verify sources
    ↓
Response with Citations
```

---

## 🔄 Retriever vs Generator Separation

The retrieval and generation stages must be implemented as separate, independent services. This separation enables testing each component independently, switching LLM providers without affecting retrieval, and ensures reproducible results. Never mix document retrieval logic with prompt construction or LLM calls in the same function.

### ✅ CORRECT: Separate Services

```python
# app/services/rag_service.py
from app.services.retrieval_service import RetrievalService
from app.services.llm_service import LLMService
from app.core.logging import logger

class RAGService:
    """Orchestrate RAG pipeline with strict separation"""

    def __init__(self, db: AsyncSession):
        self.retrieval_service = RetrievalService(db)
        self.llm_service = LLMService()

    async def process_legal_query(
        self,
        query: str,
        user_id: int,
        language: str = "English"
    ) -> dict:
        """Process query through RAG pipeline"""

        # Step 1: Normalize query
        normalized_query = self._normalize_query(query, language)
        logger.info(f"Processing query: {normalized_query[:100]}...")

        # Step 2: Retrieve relevant documents (SEPARATE SERVICE)
        retrieved_docs = await self.retrieval_service.retrieve(
            query=normalized_query,
            language=language,
            top_k=5
        )

        logger.info(f"Retrieved {len(retrieved_docs)} documents")

        # Step 3: Assemble context
        context = self._assemble_context(retrieved_docs)

        # Step 4: Generate response (SEPARATE SERVICE)
        response = await self.llm_service.generate_legal_response(
            query=normalized_query,
            context=context,
            language=language
        )

        # Step 5: Validate citations
        citation_validation = self._validate_citations(
            response=response['content'],
            retrieved_docs=retrieved_docs
        )

        if not citation_validation['valid']:
            logger.warning("Invalid citations detected")
            # Regenerate or reject

        return {
            "answer": response['content'],
            "sources": [doc.metadata for doc in retrieved_docs],
            "confidence": self._calculate_confidence(retrieved_docs),
            "citations": citation_validation['citations']
        }
```

### ❌ WRONG: Mixed Retrieval and Generation

# DON'T DO THIS!

## 📄 Chunking Standards

Consistent document chunking is critical for retrieval quality. Define standard chunk sizes, overlap strategies, and boundary detection rules. Legal documents have specific structure (sections, clauses, subsections) that should be respected during chunking to maintain context integrity.

### Chunking Configuration

```python
# app/services/document_processor.py
from typing import List
from langchain.text_splitter import RecursiveCharacterTextSplitter

class DocumentChunker:
    """Standardized document chunking"""

    # Chunking parameters (DO NOT CHANGE without versioning)
    CHUNK_SIZE = 500  # tokens (~375 words)
    CHUNK_OVERLAP = 50  # tokens (~37 words)
    SEPARATORS = ["\n\n", "\n", ". ", " ", ""]

    def __init__(self):
        self.splitter = RecursiveCharacterTextSplitter(
            chunk_size=self.CHUNK_SIZE,
            chunk_overlap=self.CHUNK_OVERLAP,
            separators=self.SEPARATORS,
            length_function=self._token_length
        )

    def chunk_document(
        self,
        text: str,
        metadata: dict
    ) -> List[dict]:
        """Chunk document with metadata preservation"""

        # Normalize text
        text = self._normalize_text(text)

        # Split into chunks
        chunks = self.splitter.split_text(text)

        # Attach metadata to each chunk
        chunked_docs = []
        for i, chunk in enumerate(chunks):
            chunk_metadata = {
                **metadata,
                "chunk_index": i,
                "chunk_total": len(chunks),
                "chunk_size": len(chunk),
                "chunking_version": "v1"  # Version tracking!
            }

            chunked_docs.append({
                "content": chunk,
                "metadata": chunk_metadata
            })

        logger.info(f"Document chunked into {len(chunked_docs)} chunks")
        return chunked_docs

    @staticmethod
    def _token_length(text: str) -> int:
        """Estimate token count (1 token ≈ 0.75 words)"""
        words = len(text.split())
        return int(words / 0.75)

    @staticmethod
    def _normalize_text(text: str) -> str:
        """Normalize text before chunking"""
        # Remove excessive whitespace
        text = ' '.join(text.split())

        # Normalize unicode (for Sinhala/Tamil)
        import unicodedata
        text = unicodedata.normalize('NFC', text)

        return text
```

## 🔍 Retrieval Service

The retrieval service is responsible for finding relevant document chunks using vector similarity search. It must handle query preprocessing, embedding generation, database querying, and result ranking. Keep this service isolated from generation logic and LLM calls.

### Retrieval Configuration

```python
# app/services/retrieval_service.py
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select, text
from app.models.document_chunk import DocumentChunk
from typing import List

class RetrievalService:
    """Centralized document retrieval service"""

    # Retrieval parameters
    DEFAULT_TOP_K = 5
    MAX_TOP_K = 20
    MIN_SIMILARITY_THRESHOLD = 0.7

    def __init__(self, db: AsyncSession):
        self.db = db
        self.embedding_service = EmbeddingService()

    async def retrieve(
        self,
        query: str,
        language: str = "English",
        top_k: int = DEFAULT_TOP_K,
        filters: dict = None
    ) -> List[DocumentChunk]:
        """Retrieve relevant document chunks"""

        # Validate top_k
        if top_k > self.MAX_TOP_K:
            logger.warning(f"top_k={top_k} exceeds max, capping at {self.MAX_TOP_K}")
            top_k = self.MAX_TOP_K

        # Generate query embedding
        query_embedding = await self.embedding_service.embed_text(query)

        # Build SQL query with pgvector
        sql = text("""
            SELECT
                id,
                content,
                metadata,
                1 - (embedding <=> :query_embedding) as similarity
            FROM document_chunks
            WHERE
                1 - (embedding <=> :query_embedding) > :threshold
                AND language = :language
            ORDER BY embedding <=> :query_embedding
            LIMIT :top_k
        """)

        result = await self.db.execute(
            sql,
            {
                "query_embedding": str(query_embedding),
                "threshold": self.MIN_SIMILARITY_THRESHOLD,
                "language": language,
                "top_k": top_k
            }
        )

        rows = result.fetchall()

        # Convert to DocumentChunk objects
        chunks = [
            DocumentChunk(
                id=row.id,
                content=row.content,
                metadata=row.metadata,
                similarity=row.similarity
            )
            for row in rows
        ]

        logger.info(f"Retrieved {len(chunks)} chunks (threshold: {self.MIN_SIMILARITY_THRESHOLD})")

        return chunks
```

### Confidence Calculation

Calculate retrieval confidence based on similarity scores, result consistency, and document coverage. Use this confidence to decide whether to proceed with generation or request clarification. Low confidence indicates the system doesn't have good information to answer the query.

```python
def _calculate_confidence(self, retrieved_docs: List[DocumentChunk]) -> str:
    """Calculate retrieval confidence level"""

    if not retrieved_docs:
        return "None"

    # Average similarity score
    avg_similarity = sum(doc.similarity for doc in retrieved_docs) / len(retrieved_docs)

    # Number of high-quality matches
    high_quality = sum(1 for doc in retrieved_docs if doc.similarity > 0.85)

    # Confidence thresholds
    if avg_similarity > 0.85 and high_quality >= 3:
        return "High"
    elif avg_similarity > 0.75 and high_quality >= 2:
        return "Medium"
    else:
        return "Low"
```

## 🎯 Top-K Retrieval Policies

Don't always retrieve a fixed number of documents. Adjust top-k dynamically based on query complexity, similarity score distribution, and available context window. Simple queries may need fewer documents while complex legal questions may require broader context.

### Dynamic Top-K Selection

```python
def determine_optimal_top_k(query: str, query_complexity: str) -> int:
    """Dynamically determine optimal top_k value"""

    # Query complexity scoring
    query_length = len(query.split())

    if query_complexity == "simple" and query_length < 10:
        return 3  # Few sources needed
    elif query_complexity == "complex" and query_length > 20:
        return 10  # More context needed
    else:
        return 5  # Default
```

### Diversity-Aware Retrieval

Avoid retrieving multiple similar chunks from the same document section. Implement diversity scoring to ensure retrieved documents cover different aspects of the query. Use maximal marginal relevance (MMR) or similar algorithms to balance relevance with diversity.

```python
async def retrieve_with_diversity(
    self,
    query: str,
    top_k: int = 5,
    diversity_threshold: float = 0.85
) -> List[DocumentChunk]:
    """Retrieve diverse documents (avoid redundancy)"""

    # Initial retrieval (get more than needed)
    candidates = await self.retrieve(query, top_k=top_k * 2)

    # Select diverse subset
    selected = [candidates[0]]  # Always take top result

    for candidate in candidates[1:]:
        # Check similarity with already selected docs
        is_diverse = all(
            self._calculate_diversity(candidate, selected_doc) < diversity_threshold
            for selected_doc in selected
        )

        if is_diverse:
            selected.append(candidate)

        if len(selected) >= top_k:
            break

    return selected

@staticmethod
def _calculate_diversity(doc1: DocumentChunk, doc2: DocumentChunk) -> float:
    """Calculate content similarity between two documents"""
    # Use embedding cosine similarity
    return cosine_similarity(doc1.embedding, doc2.embedding)
```

## 📊 Context Assembly

Format retrieved chunks into a structured context string that the LLM can easily parse. Include document metadata, citations, and clear boundaries between chunks. The format should be consistent across all queries to improve LLM reliability.

### Structured Context Formatting

```python
def _assemble_context(self, retrieved_docs: List[DocumentChunk]) -> str:
    """Assemble retrieved documents into structured context"""

    if not retrieved_docs:
        return "No relevant context found."

    context_parts = []

    for i, doc in enumerate(retrieved_docs, 1):
        # Format: [Source X] Content
        source_info = doc.metadata.get('source', 'Unknown')
        section_info = doc.metadata.get('section', '')

        context_part = f"""[Source {i}: {source_info}]
{f"Section: {section_info}" if section_info else ""}
{doc.content}
---"""

        context_parts.append(context_part)

    full_context = "\n\n".join(context_parts)

    # Truncate if too long (leave room for prompt + response)
    max_context_tokens = 4000
    if self._estimate_tokens(full_context) > max_context_tokens:
        full_context = self._truncate_context(full_context, max_context_tokens)

    return full_context

@staticmethod
def _estimate_tokens(text: str) -> int:
    """Estimate token count"""
    return int(len(text.split()) / 0.75)

def _truncate_context(self, text: str, max_tokens: int) -> str:
    """Intelligently truncate context"""
    # Keep highest-ranked sources
    sources = text.split("---")

    token_count = 0
    kept_sources = []

    for source in sources:
        source_tokens = self._estimate_tokens(source)
        if token_count + source_tokens <= max_tokens:
            kept_sources.append(source)
            token_count += source_tokens
        else:
            break

    return "\n---\n".join(kept_sources)
```

## 🏷️ Citation Formatting

Use a standardized citation format across all responses. Citations must be deterministic—the same document chunk should always produce the same citation string. This enables validation, deduplication, and user trust. Include act name, section, and subsection where applicable.

### Deterministic Citation Format

```python
class CitationFormatter:
    """Standardized citation formatting"""

    @staticmethod
    def format_citation(doc: DocumentChunk) -> str:
        """Format citation in standard format"""
        metadata = doc.metadata

        # Standard format: [Source: Act Name, Section X]
        act_name = metadata.get('act_name', 'Unknown Act')
        section = metadata.get('section', 'Unknown Section')

        return f"[Source: {act_name}, {section}]"

    @staticmethod
    def extract_citations(text: str) -> List[str]:
        """Extract all citations from text"""
        pattern = r'\[Source:.*?\]'
        return re.findall(pattern, text)

    @staticmethod
    def validate_citation_format(citation: str) -> bool:
        """Validate citation format"""
        pattern = r'^\[Source: .+, .+\]$'
        return bool(re.match(pattern, citation))
```

### Citation Injection into Response

Post-process LLM responses to inject or validate citations. Extract factual claims and match them to source documents. If the LLM generates claims without citations, either reject the response or automatically inject citations based on the retrieved context.

```python
def inject_citations(
    response: str,
    retrieved_docs: List[DocumentChunk]
) -> str:
    """Ensure response includes proper citations"""

    # If response already has citations, validate them
    existing_citations = CitationFormatter.extract_citations(response)

    if existing_citations:
        # Validate format
        for citation in existing_citations:
            if not CitationFormatter.validate_citation_format(citation):
                logger.warning(f"Invalid citation format: {citation}")
    else:
        # No citations - append source list
        logger.warning("Response missing citations - appending")

        citations_section = "\n\n**Sources:**\n"
        for doc in retrieved_docs:
            citation = CitationFormatter.format_citation(doc)
            citations_section += f"- {citation}\n"

        response += citations_section

    return response
```
