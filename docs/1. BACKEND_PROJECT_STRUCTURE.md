# OpenJustice Backend — Project Structure & Guidelines

## 📋 Overview

A **FastAPI** backend for an AI-powered legal assistance platform with **RAG (Retrieval-Augmented Generation)**, **multilingual support** (English, Sinhala, Tamil), **voice interface** (speech-to-text & text-to-speech via OpenAI), and **WhatsApp integration** (via Twilio). Built following **Clean Architecture** with PostgreSQL + pgvector for vector storage, and Alembic for database migrations.

The backend is responsible for:

- **Authentication** — JWT-based auth with HTTP-only cookie delivery, session tracking, and audit logging.
- **Chat system** — Conversation CRUD with user-owned message threads, streaming AI responses, and voice message handling.
- **RAG pipeline** — Document ingestion (PDF/TXT), LangChain text splitting with legal-domain separators, OpenAI embedding generation, and pgvector similarity search.
- **LLM orchestration** — Multi-turn conversation context building, semantic cache (pgvector-based), prompt injection detection, multilingual prompt templates, and full telemetry logging (tokens, latency, model).
- **Voice pipeline** — OpenAI Whisper transcription + OpenAI TTS synthesis, with temp file lifecycle management.
- **WhatsApp gateway** — Twilio webhook processing for incoming messages/voice, with text and audio replies.
- **Admin analytics** — Dashboard overview, usage analytics, cost analytics, multilingual analytics, platform analytics, retrieval monitoring, retrieval evaluation, security monitoring, AI evaluation, research metrics, user management, and log viewing.
- **Background evaluation** — A lifespan-managed async task running the AI evaluation pipeline at a configurable interval.

## 📝 Naming Conventions

| Element | Convention | Example |
|---|---|---|
| **Files** | snake_case | `chat_service.py`, `user_repository.py` |
| **Directories** | lowercase | `services`, `repositories`, `controllers` |
| **Test Files** | test\_\*.py | `test_auth_service.py` |
| **Classes** | PascalCase | `UserService`, `ChatRepository` |

| **Private Methods** | \_leading_underscore | `_build_messages()`, `_count_tokens()` |
| **Database Tables** | snake_case, plural | `users`, `conversations`, `document_chunks` |
| **Pydantic Schemas** | PascalCase + suffix | `LoginRequest`, `UserProfileResponse` |
| **DTOs** | PascalCase + Dto | `LoginDto`, `ConversationCreateDto` |
| **Domain Interfaces** | I-prefix | `IUserRepository`, `ILLMClient` |

| Concept | Standard Practice |
|---|---|
| **URL Naming** | Use plural nouns → `/api/users`, `/api/chats` |

| **Sorting** | Query parameters → `/api/users?sort=created_at&order=desc` |

| **Nested Resources** | Hierarchical → `/api/chats/{chat_id}/messages` |

## 🏡️ Clean Architecture Layers

The project follows **Clean Architecture** with strict dependency direction: outer layers depend on inner layers, never the reverse.

```
┌──────────────────────────────────────────────────────────────┐
│  Presentation  (controllers, schemas, middleware, routes)    │
├──────────────────────────────────────────────────────────────┤
│  Application   (services, DTOs, exceptions, prompts)        │
├──────────────────────────────────────────────────────────────┤
│  Domain        (entities, interfaces/ports, exceptions)     │
├──────────────────────────────────────────────────────────────┤
│  Infrastructure (repos, models, DB, security, external)     │
└──────────────────────────────────────────────────────────────┘
```

### 1️⃣ Domain Layer — Business Rules

Contains pure business logic with no framework dependencies.

- **Entities** — Core business objects (`User` entity)
- **Interfaces (Ports)** — Abstract contracts defining how the domain communicates with the outside world. There are 15 interfaces covering repositories, security, LLM, storage, and external services.
- **Exceptions** — Domain-specific errors like `InvalidCredentialsError`, `TokenExpiredError`, `UserAlreadyExistsError`

```python
# app/domain/interfaces/user_repository.py
from abc import ABC, abstractmethod
from typing import Optional
from uuid import UUID
from app.infrastructure.models.user import User


class IUserRepository(ABC):
    """Contract for user repositories."""

    @abstractmethod
    async def get_by_email(self, email: str) -> Optional[User]:
        raise NotImplementedError

    @abstractmethod
    async def get_by_phone(self, phone_number: str) -> Optional[User]:
        raise NotImplementedError

    @abstractmethod
    async def get_by_uuid(self, user_uuid: UUID) -> Optional[User]:
        raise NotImplementedError

    @abstractmethod
    async def create(self, user: User) -> User:
        raise NotImplementedError

    @abstractmethod
    async def get_total_count(self) -> int:
        raise NotImplementedError

    @abstractmethod
    async def list_users(self, skip: int = 0, limit: int = 100) -> list[User]:
        raise NotImplementedError

    @abstractmethod
    async def update_status(self, user_id: UUID, is_active: bool) -> Optional[User]:
        raise NotImplementedError

    @abstractmethod
    async def get_active_sessions_count(self) -> int:
        raise NotImplementedError
```

### 2️⃣ Application Layer — Use Cases & Orchestration

Contains business logic services that coordinate between the domain and infrastructure layers. Key patterns:

- **Services** — 29 service modules covering auth, chat, LLM, RAG, voice, admin analytics, etc.
- **DTOs** — Frozen dataclasses for inter-layer data transfer (no ORM leakage)
- **Prompts** — `PromptRegistry` for versioned prompt templates + `MultilingualPromptBuilder` for language-aware system prompts
- **Exceptions** — `AppError` dataclass with HTTP metadata (`status_code`, `error_code`) for clean API error mapping

```python
# app/application/services/auth_service.py
from app.application.dtos.auth_dto import LoginDto, LoginResultDto, RegisterDto, RegisterResultDto, LogoutDto
from app.domain.exceptions import InvalidCredentialsError, UserAlreadyExistsError
from app.domain.interfaces.password_hasher import PasswordHasher
from app.domain.interfaces.token_issuer import AccessTokenIssuer
from app.domain.interfaces.user_repository import IUserRepository
from app.infrastructure.models.user import User


class AuthService:
    """Business logic for authentication."""

    def __init__(
        self,
        repository: IUserRepository,
        password_hasher: PasswordHasher,
        token_issuer: AccessTokenIssuer,
        user_session_repo=None,
        audit_log_repo=None,
    ) -> None:
        self.repository = repository
        self.password_hasher = password_hasher
        self.token_issuer = token_issuer
        self.user_session_repo = user_session_repo
        self.audit_log_repo = audit_log_repo

    async def login(self, dto: LoginDto) -> LoginResultDto:
        """Authenticate a user and return a login result."""
        user = None
        if dto.email:
            user = await self.repository.get_by_email(dto.email)
        elif dto.phone_number:
            user = await self.repository.get_by_phone(dto.phone_number)

        if not user or not user.hashed_password:
            raise InvalidCredentialsError()

        if not self.password_hasher.verify_password(dto.password, user.hashed_password):
            raise InvalidCredentialsError()

        token = self.token_issuer.create_access_token(
            data={
                "sub": str(user.id),
                "role": user.role,
                "preferred_language": user.preferred_language,
            }
        )

        # Track session & audit log if repositories are provided
        if self.user_session_repo:
            await self.user_session_repo.create_session(
                user_id=user.id, session_token=uuid.uuid4(),
                channel=dto.channel, ip_address=dto.ip_address, user_agent=dto.user_agent
            )

        if self.audit_log_repo:
            await self.audit_log_repo.log_action(
                user_id=user.id, action="USER_LOGIN",
                metadata={"channel": dto.channel, "ip_address": dto.ip_address}
            )

        return LoginResultDto(
            access_token=token, uuid=user.id,
            first_name=user.first_name, last_name=user.last_name,
            role=user.role, preferred_language=user.preferred_language,
        )

    async def register(self, dto: RegisterDto) -> RegisterResultDto:
        """Register a new user and return a result (auto-login on frontend)."""
        if dto.email:
            existing = await self.repository.get_by_email(dto.email)
            if existing:
                raise UserAlreadyExistsError("A user with this email already exists")

        hashed_password = self.password_hasher.hash_password(dto.password)
        user = User(
            first_name=dto.first_name, last_name=dto.last_name,
            email=dto.email, phone_number=dto.phone_number,
            hashed_password=hashed_password,
            preferred_language=dto.preferred_language,
        )
        user = await self.repository.create(user)

        return RegisterResultDto(
            uuid=user.id, first_name=user.first_name,
            last_name=user.last_name, role=user.role,
            preferred_language=user.preferred_language,
        )
```

from typing import Optional
from uuid import UUID
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from app.domain.interfaces.user_repository import IUserRepository
from app.infrastructure.models.user import User


class UserRepository(IUserRepository):
    """Data access layer for users."""

    def __init__(self, db: AsyncSession) -> None:
        self.db = db

    async def get_by_email(self, email: str) -> Optional[User]:
        result = await self.db.execute(select(User).where(User.email == email))
        return result.scalars().first()

    async def get_by_phone(self, phone_number: str) -> Optional[User]:
        result = await self.db.execute(select(User).where(User.phone_number == phone_number))
        return result.scalars().first()

    async def get_by_uuid(self, user_uuid: UUID) -> Optional[User]:
        result = await self.db.execute(select(User).where(User.id == user_uuid))
        return result.scalars().first()

    async def create(self, user: User) -> User:
        self.db.add(user)
        await self.db.flush()
        await self.db.refresh(user)
        return user

    async def list_users(self, skip: int = 0, limit: int = 100) -> list[User]:
        result = await self.db.execute(
            select(User).order_by(User.created_at.desc()).offset(skip).limit(limit)
        )
        return list(result.scalars().all())

    async def update_profile(self, user_id: UUID, **kwargs) -> Optional[User]:
        user = await self.get_by_uuid(user_id)
        if not user:
            return None
        for key, value in kwargs.items():
            if value is not None:
                setattr(user, key, value)
        await self.db.commit()
        await self.db.refresh(user)
        return user

## 🔐 Authentication & Security

### JWT Token Flow

Authentication uses JWT tokens delivered via HTTP-only cookies. The flow is:

1. Client sends credentials to `POST /api/auth/login`
2. `AuthService` validates credentials, creates a JWT with `sub` (user UUID), `role`, and `preferred_language`
3. The controller sets the token as an HTTP-only cookie (`access_token`)
4. `AuthMiddleware` intercepts all subsequent requests, extracts the token from the cookie (or `Authorization` header), verifies it, and injects the decoded payload into `request.state.user`

```python
# app/infrastructure/security/jwt_handler.py
from datetime import datetime, timedelta, timezone
from jose import jwt
from app.config import settings


class JWTHandler:
    """Secure JWT token management."""

    def __init__(self) -> None:
        self.secret_key = settings.SECRET_KEY
        self.algorithm = settings.ALGORITHM
        self.issuer = settings.JWT_ISSUER
        self.audience = settings.JWT_AUDIENCE

        if len(self.secret_key) < 32:
            raise ValueError("SECRET_KEY must be at least 32 characters")

    def create_access_token(self, data: dict, expires_delta: timedelta = None) -> str:
        to_encode = data.copy()
        now = datetime.now(timezone.utc)
        expire = now + (expires_delta or timedelta(minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES))
        to_encode.update({"iat": now, "exp": expire, "iss": self.issuer, "aud": self.audience})
        return jwt.encode(to_encode, self.secret_key, algorithm=self.algorithm)

    def verify_token(self, token: str) -> dict:
        return jwt.decode(
            token, self.secret_key, algorithms=[self.algorithm],
            audience=self.audience, issuer=self.issuer,
        )


jwt_handler = JWTHandler()
```

### Auth Middleware

The middleware uses pure ASGI (not `BaseHTTPMiddleware`) for performance. It bypasses public paths (`/docs`, `/api/auth/login`, `/api/auth/register`, `/api/whatsapp/webhook`, `/media`, `/temp`, `/health`) and handles both HTTP and WebSocket scopes.

```python
# app/presentation/middleware/auth_middleware.py
PUBLIC_PATHS = [
    "/docs", "/openapi.json", "/redoc",
    "/api/auth/login", "/api/auth/register",
    "/api/whatsapp/webhook",
    "/media", "/temp", "/health",
]


class AuthMiddleware:
    """Pure ASGI Middleware for JWT authentication."""

    def __init__(self, app):
        self.app = app

    async def __call__(self, scope, receive, send):
        if scope["type"] not in ("http", "websocket"):
            await self.app(scope, receive, send)
            return

        request = Request(scope, receive)

        # Allow OPTIONS (CORS preflight) and public paths
        if request.method == "OPTIONS":
            await self.app(scope, receive, send)
            return

        if any(request.url.path.startswith(path) for path in PUBLIC_PATHS):
            await self.app(scope, receive, send)
            return

        # Extract token from Authorization header or cookie
        token = None
        auth_header = request.headers.get("Authorization")
        if auth_header and auth_header.startswith("Bearer "):
            token = auth_header.split(" ")[1]
        if not token:
            token = request.cookies.get(settings.AUTH_COOKIE_NAME)

        if not token:
            # Return 401 JSON response
            ...

        # Verify and inject payload
        payload = jwt_handler.verify_token(token)
        request.state.user = payload
        await self.app(scope, receive, send)
```

## 🤖 LLM & RAG Pipeline

### LLM Service

The `LLMService` is the central orchestrator that ties together the chat history, RAG context, semantic cache, prompt templates, and the OpenAI LLM client. For every user query, it:

1. Saves the user message to the conversation
2. Checks the **semantic cache** (pgvector cosine similarity) for a cached response
3. Detects the query language and selects the appropriate multilingual prompt template
4. Runs prompt security validation and sanitization
5. Builds the message array (system prompt + last 6 conversation messages + user query)
6. Calls the LLM (sync or streaming)
7. Logs telemetry (token counts via tiktoken, latency, model name)
8. Saves the response to the semantic cache for future queries
9. Saves the AI message to the conversation

### RAG Service

The `RAGService` handles document ingestion using LangChain:

1. Loads documents using `PyPDFLoader` or `TextLoader`
2. Splits text using `RecursiveCharacterTextSplitter` with legal-domain separators (section headers → paragraphs → sentences → words)
3. Generates embeddings via `OpenAIEmbeddings` (`text-embedding-3-large`)
4. Stores `DocumentChunk` rows with pgvector embeddings, chunk metadata (index, total, size, model version)

### Multilingual Prompt System

The `PromptRegistry` manages versioned prompt templates. The `MultilingualPromptBuilder` generates language-appropriate system prompts, including legal disclaimers and response formatting instructions. Language detection is handled by `LanguageDetectionService`, which analyzes the query text to determine the appropriate response language.

## 🔊 Voice Pipeline

The voice pipeline converts between speech and text using OpenAI's APIs:

- **Speech-to-Text** (`SpeechToTextService`) — Uses OpenAI Whisper API (`gpt-4o-mini-transcribe`) to transcribe audio files. Supports MP3, WAV, OGG, M4A, and WEBM formats. Automatically detects language.
- **Text-to-Speech** (`TextToSpeechService`) — Uses OpenAI TTS API (`gpt-4o-mini-tts`) to synthesize speech. Outputs `.ogg` (opus codec) for WhatsApp-compatible inline voice notes.
- **Temp File Manager** (`TempFileManager`) — Schedules automatic deletion of temporary audio files after a configurable retention period.

Audio files are served via two static mounts:
- `/media` — Persisted audio files (voice messages stored permanently)
- `/temp` — Temporary TTS output files (auto-cleaned)
