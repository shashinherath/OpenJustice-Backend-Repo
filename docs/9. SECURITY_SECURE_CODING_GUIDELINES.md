# Security & Secure Coding Guidelines

## 📋 Purpose

Protect against **OWASP Top 10** and **AI-specific threats** including prompt injection, data leakage, and unauthorized access. Ensure secure JWT handling, input sanitization, and proper authentication middleware.

---

## 🎯 Core Principles

1. **Defense in Depth** — Multiple security layers (middleware + service-level checks)
2. **Secure by Default** — `AuthMiddleware` blocks all unauthenticated requests
3. **AI Safety** — `PromptSecurityValidator` detects and prevents prompt injection
4. **Cookie-Based Auth** — JWT stored in `httpOnly` cookies, not in response bodies
5. **Secrets via Environment** — All secrets loaded from `.env` via `pydantic-settings`

## 🛡️ Prompt Injection Prevention

The `PromptSecurityValidator` (located in `app/infrastructure/security/prompt_security.py`) detects and sanitizes prompt injection attempts before they reach the LLM. It is called inside `LLMService._build_messages()` on every query.

### Detection Patterns

```python
# app/infrastructure/security/prompt_security.py
class PromptSecurityValidator:
    """Detect and prevent prompt injection attacks, and validate neutrality."""

    INJECTION_PATTERNS = [
        r'ignore\s+(previous|above|all)\s+instructions',
        r'disregard\s+(previous|above|instructions)',
        r'new\s+instructions?:',
        r'system\s*:',
        r'assistant\s*:',
        r'<\|.*?\|>',            # Special tokens
        r'\[INST\].*?\[/INST\]', # Instruction tags
    ]

    @classmethod
    def is_safe(cls, text: str) -> Tuple[bool, List[Dict[str, Any]]]:
        """Check if user text contains injection attempts."""
        violations = []
        text_lower = text.lower()

        for pattern in cls.INJECTION_PATTERNS:
            matches = re.findall(pattern, text_lower, re.IGNORECASE)
            if matches:
                violations.append({
                    "pattern": pattern, "matches": matches, "severity": "high"
                })

        return len(violations) == 0, violations

    @classmethod
    def sanitize(cls, text: str) -> str:
        """Remove potentially dangerous patterns."""
        text = ''.join(char for char in text if char.isprintable() or char.isspace())
        for pattern in cls.INJECTION_PATTERNS:
            text = re.sub(pattern, '', text, flags=re.IGNORECASE)
        text = ' '.join(text.split())
        return text.strip()
```

### Integration in LLMService

Both `is_safe()` and `sanitize()` are called before prompt construction:

```python
# app/application/services/llm_service.py
async def _build_messages(self, conversation_id, user_id, query, context):
    # Security check
    is_safe, violations = PromptSecurityValidator.is_safe(query)
    if not is_safe:
        logger.warning(f"Prompt injection detected: {violations}")

    # Sanitize before using in prompt
    safe_query = PromptSecurityValidator.sanitize(query)

    # Build system prompt with sanitized query
    detected_lang = LanguageDetectionService.detect_language(safe_query)
    system_prompt = MultilingualPromptBuilder.build_system_prompt(detected_lang, context)

    # Append security marker to prevent system instruction leakage
    system_prompt += "\n\n[SECURITY_MARKER: OpenJustice_2025]"
    ...
```

### Neutral Language Validation

The validator also checks AI responses for prohibited legal advice phrases:

```python
PROHIBITED_LEGAL_PHRASES = [
    "you should", "you must", "i recommend", "my advice is",
    "definitely", "certainly will", "guaranteed", "obviously", "clearly wrong",
]

@classmethod
def validate_neutral_language(cls, response: str) -> Tuple[bool, List[str]]:
    """Check if AI response maintains neutral language."""
    violations = []
    response_lower = response.lower()
    for phrase in cls.PROHIBITED_LEGAL_PHRASES:
        if phrase in response_lower:
            violations.append(phrase)
    return len(violations) == 0, violations
```

## 🔐 JWT Authentication

### JWTHandler

The `JWTHandler` (located in `app/infrastructure/security/jwt_handler.py`) manages token creation and verification with issuer/audience validation:

```python
# app/infrastructure/security/jwt_handler.py
class JWTHandler:
    """Secure JWT token management."""

    def __init__(self):
        self.secret_key = settings.SECRET_KEY
        self.algorithm = settings.ALGORITHM       # "HS256"
        self.issuer = settings.JWT_ISSUER          # "openjustice"
        self.audience = settings.JWT_AUDIENCE      # "openjustice-api"
        self.access_token_expire_minutes = settings.ACCESS_TOKEN_EXPIRE_MINUTES

        if len(self.secret_key) < 32:
            raise ValueError("SECRET_KEY must be at least 32 characters")

    def create_access_token(self, data: Dict[str, Any], expires_delta=None) -> str:
        to_encode = data.copy()
        now = datetime.now(timezone.utc)
        expire = now + (expires_delta or timedelta(minutes=self.access_token_expire_minutes))
        to_encode.update({"iat": now, "exp": expire, "iss": self.issuer, "aud": self.audience})
        return jwt.encode(to_encode, self.secret_key, algorithm=self.algorithm)

    def verify_token(self, token: str) -> Dict[str, Any]:
        try:
            return jwt.decode(token, self.secret_key, algorithms=[self.algorithm],
                              audience=self.audience, issuer=self.issuer)
        except ExpiredSignatureError:
            raise TokenExpiredError("Token has expired")
        except JWTClaimsError:
            raise InvalidTokenError("Invalid token claims")
        except JWTError:
            raise InvalidTokenError("Could not validate credentials")

jwt_handler = JWTHandler()  # Global singleton
```

### Auth Middleware

The `AuthMiddleware` is a pure ASGI middleware that intercepts every request, extracts the JWT from the `Authorization` header or cookie, verifies it, and injects the payload into `request.state.user`:

```python
# app/presentation/middleware/auth_middleware.py
PUBLIC_PATHS = [
    "/docs", "/openapi.json", "/redoc",
    "/api/auth/login", "/api/auth/register",
    "/api/whatsapp/webhook",
    "/media", "/temp", "/health",
]


class AuthMiddleware:
    """Pure ASGI Middleware for JWT authentication."""

    async def __call__(self, scope, receive, send):
        request = Request(scope, receive)

        # Skip public paths and CORS preflight
        if any(request.url.path.startswith(path) for path in PUBLIC_PATHS):
            await self.app(scope, receive, send)
            return

        # Extract token from header or cookie
        token = None
        auth_header = request.headers.get("Authorization")
        if auth_header and auth_header.startswith("Bearer "):
            token = auth_header.split(" ")[1]

        if not token and settings.AUTH_COOKIE_NAME:
            token = request.cookies.get(settings.AUTH_COOKIE_NAME)

        if not token:
            return JSONResponse(status_code=401, content={"error": "Not authenticated"})

        # Verify and inject user payload
        payload = jwt_handler.verify_token(token)
        request.state.user = payload
        await self.app(scope, receive, send)
```

### Cookie-Based Token Storage

Tokens are set as `httpOnly` cookies on login — never returned in the response body for XSS protection:

```python
# app/presentation/controllers/auth_controller.py
response.set_cookie(
    key=settings.AUTH_COOKIE_NAME,     # "access_token"
    value=result.access_token,
    httponly=True,                      # Prevents JavaScript access
    secure=cookie_secure,              # HTTPS only in production
    samesite=settings.AUTH_COOKIE_SAMESITE,  # "strict"
    max_age=settings.ACCESS_TOKEN_EXPIRE_MINUTES * 60,
    path="/",
)
```

## 🏗️ Exception Hierarchy

The project uses a clean architecture exception hierarchy that maps domain errors to HTTP responses via global exception handlers.

### Domain Exceptions

```python
# app/domain/exceptions/base.py
class DomainError(Exception):
    """Base class for domain-level errors."""

# app/domain/exceptions/auth.py
class AuthenticationFailure(DomainError):
    """Base for authentication failures."""

class InvalidCredentialsError(AuthenticationFailure):
    def __init__(self, message="Invalid credentials"): ...

class TokenExpiredError(AuthenticationFailure):
    def __init__(self, message="Token has expired"): ...

class InvalidTokenError(AuthenticationFailure):
    def __init__(self, message="Could not validate credentials"): ...

class UserAlreadyExistsError(DomainError):
    def __init__(self, message="A user with this identifier already exists"): ...
```

### Application Exceptions

```python
# app/application/exceptions/app_errors.py
@dataclass
class AppError(Exception):
    """Base application error with HTTP metadata."""
    message: str
    status_code: int
    error_code: str

class AuthenticationError(AppError):
    def __init__(self, message="Invalid credentials"):
        super().__init__(message=message, status_code=401, error_code="AUTHENTICATION_ERROR")
```

### Global Error Handler

```python
# app/presentation/middleware/error_handler.py
def setup_error_handlers(app: FastAPI) -> None:
    @app.exception_handler(AppError)
    async def app_error_handler(request, exc: AppError):
        return JSONResponse(status_code=exc.status_code, content=ErrorResponse(
            error=ErrorDetail(code=exc.error_code, message=exc.message)
        ).model_dump(mode="json"))

    @app.exception_handler(AuthenticationFailure)
    async def authentication_failure_handler(request, exc):
        return JSONResponse(status_code=401, content=ErrorResponse(
            error=ErrorDetail(code="AUTHENTICATION_ERROR", message=exc.message)
        ).model_dump(mode="json"))

    @app.exception_handler(Exception)
    async def unhandled_exception_handler(request, exc):
        return JSONResponse(status_code=500, content=ErrorResponse(
            error=ErrorDetail(code="INTERNAL_SERVER_ERROR",
                              message="An unexpected error occurred. Please try again.")
        ).model_dump(mode="json"))
```

This ensures users **never see** stack traces, SQL errors, or internal details.

## 🔑 Secrets Management

All secrets are loaded via `pydantic-settings` from `.env`. Never hardcode secrets in source code.

### Configuration

```python
# app/config.py
class Settings(BaseSettings):
    SECRET_KEY: str = "your-secret-key-change-this-in-production"
    ALGORITHM: str = "HS256"
    ACCESS_TOKEN_EXPIRE_MINUTES: int = 30
    OPENAI_API_KEY: str
    TWILIO_ACCOUNT_SID: Optional[str] = None
    TWILIO_AUTH_TOKEN: Optional[str] = None

    model_config = SettingsConfigDict(env_file=".env", case_sensitive=True, extra="ignore")
```

### Validation at Startup

The `JWTHandler.__init__()` validates `SECRET_KEY` length at startup:

```python
if len(self.secret_key) < 32:
    raise ValueError("SECRET_KEY must be at least 32 characters")
```

## 📋 Checklist: Security Implementation

✅ **Prompt Injection**

- [ ] `PromptSecurityValidator.is_safe()` called before prompt construction
- [ ] `PromptSecurityValidator.sanitize()` used for all user queries
- [ ] Security marker appended to system prompts
- [ ] Injection attempts logged as warnings

✅ **JWT Security**

- [ ] Tokens stored in `httpOnly`, `secure`, `samesite=strict` cookies
- [ ] Token expiration enforced (default: 30 min)
- [ ] Issuer and audience validated on every request
- [ ] `SECRET_KEY` minimum 32 characters enforced

✅ **Authentication Middleware**

- [ ] `AuthMiddleware` registered in `main.py`
- [ ] All routes protected except `PUBLIC_PATHS`
- [ ] Token extracted from header (`Bearer`) or cookie
- [ ] User payload injected into `request.state.user`

✅ **Error Handling**

- [ ] `setup_error_handlers()` registered in `main.py`
- [ ] Internal errors return generic messages (no stack traces)
- [ ] Domain exceptions mapped to appropriate HTTP status codes

## 🚨 Common Mistakes to Avoid

❌ **Hardcoded secrets**

```python
# BAD
API_KEY = "sk-1234567890abcdef"
```

❌ **Returning tokens in JSON**

```python
# BAD — use httpOnly cookies instead
return {"access_token": token}
```

❌ **No prompt injection check**

```python
# BAD — always check before building prompts
system_prompt = build_prompt(raw_user_input)
```

❌ **Exposing internal errors**

```python
# BAD — unhandled_exception_handler catches this
return {"error": str(e)}  # Shows stack traces!
```
