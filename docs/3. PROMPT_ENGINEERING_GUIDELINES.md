# Prompt Engineering & Management Guidelines

## 📋 Purpose

Ensure **consistent**, **safe**, and **testable** prompts for the OpenJustice legal assistance platform. Prevent prompt injection, maintain neutrality, and support multilingual operations.

---

## 🎯 Core Principles

1. **Template-Based** — All prompts stored in `app/application/prompts/`
2. **Version Controlled** — `PromptRegistry` manages named + versioned templates
3. **Structured Inputs** — `MultilingualPromptBuilder` handles formatting
4. **Injection-Safe** — `PromptSecurityValidator` validates and sanitizes inputs
5. **Neutral Language** — Prohibited phrase detection for legal neutrality

---

## 📁 Prompt Template Storage

All prompt templates live under `app/application/prompts/`:

```
app/application/prompts/
├── __init__.py          # PromptRegistry class + get_prompt() helper
└── multilingual.py      # Language templates + MultilingualPromptBuilder
```

### PromptRegistry Pattern

The `PromptRegistry` is a class-level dictionary that stores named templates with version keys. Templates are registered at module import time and retrieved by name + version:

```python
# app/application/prompts/__init__.py
class PromptRegistry:
    """Manage all prompt templates across the platform."""

    _templates: Dict[str, Dict[str, str]] = {}

    @classmethod
    def register(cls, name: str, version: str, template: str) -> None:
        if name not in cls._templates:
            cls._templates[name] = {}
        cls._templates[name][version] = template

    @classmethod
    def get(cls, name: str, version: str = "latest") -> str:
        if name not in cls._templates:
            raise ValueError(f"Unknown prompt template: {name}")
        templates = cls._templates[name]
        if version == "latest":
            version = max(templates.keys())  # Highest version string
        if version not in templates:
            raise ValueError(f"Version {version} not found for {name}")
        return templates[version]

    @classmethod
    def list_versions(cls, name: str) -> list[str]:
        return list(cls._templates.get(name, {}).keys())


def get_prompt(name: str, version: str = "latest") -> str:
    """Convenience function to get a prompt template."""
    return PromptRegistry.get(name, version)
```

### ❌ DON'T: Hardcode Prompts in Services

```python
# BAD — prompts must come from PromptRegistry
system_msg = "You are a legal assistant for Sri Lankan law..."
```

### ✅ DO: Register and Retrieve from Registry

```python
# GOOD — register at module level, retrieve via PromptRegistry.get()
PromptRegistry.register("legal_assistant_english", "v1", LEGAL_ASSISTANT_EN_V1)

# In service:
template = PromptRegistry.get("legal_assistant_english", "latest")
system_prompt = template.format(context=context)
```

## 🌍 Multilingual Prompt Handling

The `MultilingualPromptBuilder` maps language codes (`en`, `si`, `ta`) to registered template names and formats them with the retrieval context.

```python
# app/application/prompts/multilingual.py
class MultilingualPromptBuilder:
    """Build language-specific system prompts securely."""

    LANGUAGE_MAP = {
        "en": "legal_assistant_english",
        "si": "legal_assistant_sinhala",
        "ta": "legal_assistant_tamil",
    }

    @classmethod
    def build_system_prompt(cls, language_code: str, context: str) -> str:
        """Fetch and build the correct prompt version."""
        # Fallback to English if unknown language code
        template_name = cls.LANGUAGE_MAP.get(language_code, "legal_assistant_english")
        template = PromptRegistry.get(template_name, "latest")
        return template.format(context=context)
```

### Language Detection

The `LanguageDetectionService` determines the user's language by analyzing Unicode character distribution. It checks Sinhala (U+0D80–0DFF), Tamil (U+0B80–0BFF), and Latin character ratios:

```python
# app/application/services/language_detection_service.py
class LanguageDetectionService:
    """Detect language of user input through native Unicode bounds."""

    SUPPORTED_LANGUAGES = {
        'en': 'English',
        'si': 'Sinhala',
        'ta': 'Tamil'
    }

    @classmethod
    def detect_language(cls, text: str) -> str:
        """Determines the primary language based on Unicode block prevalence."""
        if not text or len(text.strip()) < 2:
            return cls.DEFAULT_LANGUAGE

        language_code = cls._detect_by_unicode(text)
        return cls.SUPPORTED_LANGUAGES.get(language_code, cls.DEFAULT_LANGUAGE)

    @staticmethod
    def _detect_by_unicode(text: str) -> Optional[str]:
        sinhala_chars = len(re.findall(r'[\u0D80-\u0DFF]', text))
        tamil_chars = len(re.findall(r'[\u0B80-\u0BFF]', text))
        latin_chars = len(re.findall(r'[a-zA-Z]', text))

        total_chars = sinhala_chars + tamil_chars + latin_chars
        if total_chars == 0:
            return None

        if sinhala_chars / total_chars > 0.3:
            return 'si'
        elif tamil_chars / total_chars > 0.3:
            return 'ta'
        elif latin_chars / total_chars > 0.5:
            return 'en'
        return None
```

## 🛡️ Prompt Injection Prevention

The `PromptSecurityValidator` (located in `app/infrastructure/security/prompt_security.py`) provides two layers of defense: **detection** and **sanitization**.

### Injection Detection

Checks user input against known injection patterns. Returns a tuple of `(is_safe, violations)`:

```python
# app/infrastructure/security/prompt_security.py
class PromptSecurityValidator:
    """Detect and prevent prompt injection attacks, and validate neutrality."""

    INJECTION_PATTERNS = [
        r'ignore\s+(previous|above|all)\s+instructions',
        r'disregard\s+(previous|above|instructions)',
        r'new\s+instructions?:',
        r'system\s*:',
        r'assistant\s*:',
        r'<\|.*?\|>',           # Special tokens
        r'\[INST\].*?\[/INST\]', # Instruction tags
    ]

    @classmethod
    def is_safe(cls, text: str) -> Tuple[bool, List[Dict[str, Any]]]:
        """Check if user text contains injection attempts."""
        violations = []
        text_lower = text.lower()

        for pattern in cls.INJECTION_PATTERNS:
            matches = re.findall(pattern, text_lower, re.IGNORECASE)
            if matches:
                violations.append({
                    "pattern": pattern,
                    "matches": matches,
                    "severity": "high"
                })

        return len(violations) == 0, violations
```

### Input Sanitization

Removes control characters and injection patterns from user input:

```python
    @classmethod
    def sanitize(cls, text: str) -> str:
        """Remove potentially dangerous patterns."""
        # Remove control characters
        text = ''.join(char for char in text if char.isprintable() or char.isspace())

        # Remove injection patterns
        for pattern in cls.INJECTION_PATTERNS:
            text = re.sub(pattern, '', text, flags=re.IGNORECASE)

        # Normalize whitespace
        text = ' '.join(text.split())
        return text.strip()
```

### Usage in LLMService

The `LLMService` calls both `is_safe()` and `sanitize()` before constructing the prompt:

```python
# In LLMService.generate_response():
is_safe, violations = PromptSecurityValidator.is_safe(user_query)
if not is_safe:
    logger.warning(f"Prompt injection attempt: {violations}")
    # Log security event and reject or sanitize

sanitized_query = PromptSecurityValidator.sanitize(user_query)
```

## ⚖️ Neutral Legal Language Validation

The `PromptSecurityValidator` also validates that AI responses maintain neutral, factual language. Legal information systems must not give legal advice or use biased language.

### Prohibited Phrases

```python
PROHIBITED_LEGAL_PHRASES = [
    "you should",
    "you must",
    "i recommend",
    "my advice is",
    "definitely",
    "certainly will",
    "guaranteed",
    "obviously",
    "clearly wrong",
]
```

### Response Validation

```python
@classmethod
def validate_neutral_language(cls, response: str) -> Tuple[bool, List[str]]:
    """Check if AI response maintains neutral language."""
    violations = []
    response_lower = response.lower()

    for phrase in cls.PROHIBITED_LEGAL_PHRASES:
        if phrase in response_lower:
            violations.append(phrase)

    return len(violations) == 0, violations
```

## 📋 Checklist: Before Deploying New Prompt

✅ **Structure**

- [ ] Stored in `app/application/prompts/`
- [ ] Registered in `PromptRegistry` with version
- [ ] Version number incremented for changes
- [ ] Language-specific formatting correct

✅ **Safety**

- [ ] No hardcoded user data in template
- [ ] Injection-resistant structure (uses `{context}` placeholder, not string concat)
- [ ] Neutral language rules documented in prompt
- [ ] Input validation via `PromptSecurityValidator`

✅ **Multilingual**

- [ ] All three languages included (English, Sinhala, Tamil)
- [ ] Each template written natively (not translated from English)
- [ ] Unicode handling tested
- [ ] Citation format consistent across languages: `[Source: Act Name, Section Number]`

## 🚨 Common Mistakes to Avoid

❌ **Hardcoded prompts in services**

```python
# BAD — use PromptRegistry.get()
system_msg = "You are a legal assistant..."
```

❌ **String concatenation**

```python
# BAD — use template.format(context=context) instead
prompt = "Context: " + context + " Question: " + query
```

❌ **No injection validation**

```python
# BAD — always call PromptSecurityValidator.is_safe() first
prompt = build_prompt(user_input)
```

❌ **Mixed language templates**

```python
# BAD — write fully native templates
SINHALA_PROMPT = "You are a legal assistant. සියලු උපදෙස් ඉතා වැදගත්..."
```

❌ **No version tracking**

```python
# BAD — always use PromptRegistry.register() with a version string
LEGAL_PROMPT = "..."  # Which version is this?
```
