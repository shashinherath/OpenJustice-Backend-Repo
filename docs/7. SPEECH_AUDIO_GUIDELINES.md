# Speech & Audio Processing Guidelines

## 📋 Purpose

Safely handle **voice input/output** for the OpenJustice platform using **OpenAI Whisper (STT)** and **OpenAI TTS**. Ensure async processing, temporary file management, and proper integration with the chat pipeline.

---

## 🎯 Core Principles

1. **Async Processing** — All audio I/O runs in threads via `asyncio.to_thread()`
2. **Temporary Storage** — Auto-delete audio files after configurable retention
3. **Dual Storage** — Temp files for processing, persistent media for playback
4. **OpenAI-Only** — Both STT and TTS use OpenAI endpoints (no multi-provider abstraction)
5. **Telemetry** — Audio requests logged via `AudioRequest` model + `IAudioLogRepository`

---

## 🎤 Voice Message Pipeline

The complete voice message flow is handled in a single controller endpoint (`POST /chats/{id}/messages/voice`):

```
User uploads audio → Save to temp → Whisper STT → Transcribed text
    → Retrieve context (RAG) → Generate LLM response → OpenAI TTS
    → Save synthesized audio → Return audio file response
```

### Controller Implementation

```python
# app/presentation/controllers/chat_controller.py
@router.post("/{conversation_id}/messages/voice")
async def voice_message(
    conversation_id: UUID,
    request: Request,
    file: UploadFile = File(...),
    db: AsyncSession = Depends(get_db),
    service: ChatService = Depends(get_chat_service),
):
    """Process voice note → AI reply → return synthesized audio."""
    user_id = get_current_user_id(request)

    # 1. Save uploaded file to temp directory
    in_audio_path = await TempFileManager.save_upload_file(file)
    user_audio_path = _persist_audio_file(in_audio_path, "voice_user")

    # 2. Transcribe with Whisper
    stt_service = SpeechToTextService()
    query = await stt_service.transcribe_audio(in_audio_path)

    # 3. Retrieve context via RAG
    chunks, confidence = await retrieval_service.retrieve(query=query)
    context = "\n\n---\n\n".join([f"REFERENCE TEXT:\n{c.content}" for c in chunks])

    # 4. Generate LLM response
    ai_reply = await llm_service.generate_response(
        conversation_id, user_id, query, context,
        message_type="voice", user_audio_path=user_audio_path,
    )

    # 5. Synthesize audio response
    tts_service = TextToSpeechService()
    out_audio_path = await tts_service.synthesize_speech(ai_reply)
    ai_audio_path = _persist_audio_file(out_audio_path, "voice_ai")

    # 6. Save AI message with audio path and return audio file
    await service.add_message(conversation_id, user_id, MessageCreateDto(
        sender="ai", content=ai_reply, message_type="voice", audio_path=ai_audio_path,
    ))

    return FileResponse(path=ai_audio_path, media_type="audio/ogg", filename="response.ogg")
```

There is also a `GET /chats/{id}/messages/{msg_id}/audio` endpoint that returns existing voice message audio or synthesizes it on demand using TTS.

## 🎙️ Speech-to-Text (Whisper)

The `SpeechToTextService` wraps OpenAI's Whisper API for async transcription. It reads audio files in a background thread to avoid blocking the event loop and sends them to the Whisper endpoint.

### Implementation

```python
# app/application/services/speech_to_text_service.py
import asyncio
from openai import AsyncOpenAI
from app.config import settings


class SpeechToTextService:
    """Async speech-to-text wrapper utilizing OpenAI Whisper API."""

    def __init__(self):
        self.client = AsyncOpenAI(api_key=settings.OPENAI_API_KEY)
        self.model = settings.WHISPER_MODEL   # "gpt-4o-mini-transcribe"

    async def transcribe_audio(self, audio_file_path: str) -> str:
        """Transcribe audio file to text asynchronously.
        Whisper handles: MP3, MP4, MPEG, MPGA, M4A, WAV, and WEBM."""

        logger.info(f"Transcribing audio sequence: {audio_file_path}")

        try:
            # Read file bytes in background thread
            def _read_audio():
                with open(audio_file_path, 'rb') as f:
                    return f.read()

            audio_bytes = await asyncio.to_thread(_read_audio)
            filename = os.path.basename(audio_file_path)

            # Send to Whisper API
            response = await self.client.audio.transcriptions.create(
                model=self.model,
                file=(filename, audio_bytes),
                response_format="text"
            )

            logger.info("Transcription successful.")
            return str(response).strip()

        except Exception as e:
            logger.error(f"Transcription failed: {e}", exc_info=True)
            raise ValueError(f"OpenAI Whisper failed to convert audio: {str(e)}")
```

### Key Details

- **Model**: `gpt-4o-mini-transcribe` (configured via `settings.WHISPER_MODEL`)
- **Language detection**: Whisper automatically detects the language — no hint needed
- **Response format**: `"text"` — returns plain text, no JSON metadata
- **File reading**: Uses `asyncio.to_thread()` to read file bytes without blocking

## 🔊 Text-to-Speech (TTS)

The `TextToSpeechService` converts LLM response text to audio using OpenAI's TTS API. Output is saved as `.ogg` (Opus codec) for WhatsApp compatibility.

### Implementation

```python
# app/application/services/text_to_speech_service.py
import os, uuid, asyncio
from openai import AsyncOpenAI
from app.config import settings
from app.application.services.temp_file_manager import TempFileManager


class TextToSpeechService:
    """Async text-to-speech wrapper utilizing OpenAI TTS."""

    def __init__(self):
        self.client = AsyncOpenAI(api_key=settings.OPENAI_API_KEY)
        self.model = settings.TTS_MODEL    # "gpt-4o-mini-tts"
        self.voice = settings.TTS_VOICE    # "alloy"

    async def synthesize_speech(self, text: str) -> str:
        """Convert text to speech. Saves as .ogg (opus) for WhatsApp inline playback."""
        if not text or len(text.strip()) == 0:
            raise ValueError("TTS text cannot be empty.")

        logger.info(f"Synthesizing speech: {len(text)} chars using {self.voice}")

        try:
            response = await self.client.audio.speech.create(
                model=self.model,
                voice=self.voice,
                input=text,
                response_format="opus"
            )

            # Write audio bytes to disk in thread to prevent blocking
            output_dir = settings.AUDIO_TEMP_DIR
            filename = f"tts_out_{uuid.uuid4()}.ogg"
            output_path = os.path.join(output_dir, filename)

            def _ensure_dir_and_write(response_obj, file_path, d_dir):
                os.makedirs(d_dir, exist_ok=True)
                with open(file_path, 'wb') as f:
                    for chunk in response_obj.iter_bytes():
                        f.write(chunk)

            await asyncio.to_thread(_ensure_dir_and_write, response, output_path, output_dir)

            # Schedule temp file cleanup
            TempFileManager.schedule_deletion(output_path)

            logger.info(f"Speech synthesized: {output_path}")
            return output_path

        except Exception as e:
            logger.error(f"TTS failed: {e}", exc_info=True)
            raise ValueError(f"Text-to-speech failed: {str(e)}")
```

### Key Details

- **Model**: `gpt-4o-mini-tts` (configured via `settings.TTS_MODEL`)
- **Voice**: `alloy` (configured via `settings.TTS_VOICE`)
- **Output format**: `opus` → saved as `.ogg` for WhatsApp inline voice note rendering
- **Cleanup**: `TempFileManager.schedule_deletion()` called automatically after write

## 💾 Temporary File Management

The `TempFileManager` handles saving uploaded audio, downloading WhatsApp media from Twilio, and scheduling automatic deletion.

### Implementation

```python
# app/application/services/temp_file_manager.py
import os, uuid, asyncio
import httpx
from app.config import settings


class TempFileManager:
    """Manages raw audio binary files and Twilio downloads."""

    @staticmethod
    async def save_upload_file(upload_file) -> str:
        """Save a FastAPI UploadFile to the local temp directory."""
        os.makedirs(settings.AUDIO_TEMP_DIR, exist_ok=True)

        ext = ".webm"
        if upload_file.filename and "." in upload_file.filename:
            ext = f".{upload_file.filename.split('.')[-1]}"

        filename = f"web_in_{uuid.uuid4()}{ext}"
        file_path = os.path.join(settings.AUDIO_TEMP_DIR, filename)

        content = await upload_file.read()
        await asyncio.to_thread(lambda: open(file_path, 'wb').write(content))

        TempFileManager.schedule_deletion(file_path)
        return file_path

    @staticmethod
    async def download_twilio_audio(media_url: str) -> str:
        """Download Twilio WhatsApp audio for local Whisper consumption."""
        os.makedirs(settings.AUDIO_TEMP_DIR, exist_ok=True)

        filename = f"twilio_in_{uuid.uuid4()}.ogg"
        file_path = os.path.join(settings.AUDIO_TEMP_DIR, filename)

        auth = None
        if settings.TWILIO_ACCOUNT_SID and settings.TWILIO_AUTH_TOKEN:
            auth = (settings.TWILIO_ACCOUNT_SID, settings.TWILIO_AUTH_TOKEN)

        async with httpx.AsyncClient(timeout=30.0, follow_redirects=True) as client:
            response = await client.get(media_url, auth=auth)
            response.raise_for_status()
            with open(file_path, 'wb') as f:
                f.write(response.content)

        TempFileManager.schedule_deletion(file_path)
        return file_path

    @staticmethod
    def schedule_deletion(file_path: str):
        """Schedule background task to delete file after retention period."""
        asyncio.create_task(
            TempFileManager._delete_after_delay(file_path, settings.AUDIO_RETENTION_MINUTES * 60)
        )

    @staticmethod
    async def _delete_after_delay(file_path: str, seconds: int):
        await asyncio.sleep(seconds)
        try:
            if os.path.exists(file_path):
                os.remove(file_path)
                logger.info(f"Temporary audio flushed: {file_path}")
        except Exception as e:
            logger.error(f"Failed to flush temp file {file_path}: {e}")
```

### Dual Storage Strategy

The system uses two directories:

| Directory | Setting | Purpose | Lifecycle |
|---|---|---|---|
| `temp/audio` | `AUDIO_TEMP_DIR` | Processing workspace (STT input, TTS output) | Auto-deleted after `AUDIO_RETENTION_MINUTES` |
| `media/audio` | `AUDIO_MEDIA_DIR` | Persistent audio for message playback | Kept until message/conversation deleted |

The `_persist_audio_file()` helper in the chat controller copies temp files to the media directory for long-term storage:

```python
def _persist_audio_file(source_path: str, prefix: str) -> str:
    """Copy audio file from temp to persistent media directory."""
    os.makedirs(settings.AUDIO_MEDIA_DIR, exist_ok=True)
    suffix = Path(source_path).suffix or ".ogg"
    target_path = Path(settings.AUDIO_MEDIA_DIR) / f"{prefix}_{uuid.uuid4().hex}{suffix}"
    shutil.copy2(source_path, target_path)
    return str(target_path)
```

## 📊 Audio Telemetry

Audio processing is tracked via the `AudioRequest` ORM model and `IAudioLogRepository` interface.

### AudioRequest Model

```python
# app/infrastructure/models/audio_request.py
class AudioRequest(Base):
    """Records STT/TTS audio processing requests."""
    __tablename__ = "audio_requests"

    id: Mapped[uuid.UUID] = mapped_column(PGUUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    user_id: Mapped[Optional[uuid.UUID]] = mapped_column(PGUUID(as_uuid=True), ForeignKey("users.id"))
    audio_type: Mapped[Optional[str]] = mapped_column(String(20))    # "stt" or "tts"
    language: Mapped[Optional[str]] = mapped_column(String(10))
    duration_seconds: Mapped[Optional[float]] = mapped_column(Float)
    characters_generated: Mapped[Optional[int]] = mapped_column(Integer)
    provider: Mapped[Optional[str]] = mapped_column(String(50))
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())

    user: Mapped[Optional["User"]] = relationship("User", back_populates="audio_requests")
```

### Audio Log Interface

```python
# app/domain/interfaces/audio_log_repository.py
class IAudioLogRepository(ABC):
    """Interface for tracking voice AI telemetry."""

    @abstractmethod
    async def log_audio_request(
        self,
        user_id: uuid.UUID,
        audio_type: str,          # "stt" or "tts"
        language: Optional[str],
        duration_seconds: float,
        provider: str
    ) -> uuid.UUID:
        """Logs STT or TTS processing details."""
        pass
```

## ⚙️ Configuration

All audio-related settings are centralized in `app/config.py`:

```python
class Settings(BaseSettings):
    # Whisper (Speech-to-Text)
    WHISPER_MODEL: str = "gpt-4o-mini-transcribe"

    # TTS (Text-to-Speech)
    TTS_MODEL: str = "gpt-4o-mini-tts"
    TTS_VOICE: str = "alloy"

    # Audio Processing & Storage Limits
    MAX_AUDIO_DURATION_SECONDS: int = 300        # 5 minutes max
    MAX_AUDIO_FILE_SIZE_MB: int = 25             # 25 MB max
    AUDIO_TEMP_DIR: str = "temp/audio"           # Temp processing directory
    AUDIO_MEDIA_DIR: str = "media/audio"         # Persistent storage
    AUDIO_RETENTION_MINUTES: int = 60            # Auto-delete temp after 1 hour

    # Allowed formats for upload validation
    ALLOWED_AUDIO_FORMATS: list[str] = ["mp3", "wav", "ogg", "m4a"]
```

## 🚨 Common Mistakes to Avoid

❌ **Synchronous file I/O**

```python
# BAD — use asyncio.to_thread() for file reads/writes
with open(file_path, 'rb') as f:
    data = f.read()  # Blocks the event loop!
```

❌ **No temp file cleanup**

```python
# BAD — always call TempFileManager.schedule_deletion()
save_audio(file)  # File will accumulate indefinitely
```

❌ **Hardcoded model names**

```python
# BAD — use settings.WHISPER_MODEL and settings.TTS_MODEL
model = "whisper-1"
```

❌ **Skipping persistent copy**

```python
# BAD — temp files are auto-deleted; copy to media/ for playback
return FileResponse(path=temp_path)  # File might not exist later
```
