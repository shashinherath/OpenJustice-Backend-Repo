# 6️⃣ Speech & Audio Processing Guidelines

## 📋 Purpose

Safely handle **voice input/output** for the OpenJustice platform using **Whisper (STT)** and **TTS** providers. Ensure proper audio format handling, async processing, and secure temporary storage.

---

## 🎯 Core Principles

1. **Format Validation** - Only accept safe audio formats
2. **Async Processing** - Non-blocking audio operations
3. **Temporary Storage** - Auto-delete after processing
4. **Error Resilience** - Handle provider failures gracefully
5. **Provider Abstraction** - Easy provider switching

## 🎤 Accepted Audio Formats & Duration

Define strict audio file format and duration limits to prevent abuse and ensure reliable processing. Support common formats (MP3, WAV, M4A) but validate file integrity before processing. Enforce maximum duration limits to control processing costs and prevent denial-of-service attacks.

### Supported Formats

```python
# app/config.py

class AudioSettings(BaseSettings):
    """Audio processing configuration"""

    # Accepted formats
    ACCEPTED_AUDIO_FORMATS = [
        'audio/mpeg',           # MP3
        'audio/mp4',            # M4A
        'audio/wav',            # WAV
        'audio/webm',           # WebM
        'audio/ogg',            # OGG
        'audio/flac'            # FLAC
    ]

    ACCEPTED_FILE_EXTENSIONS = ['.mp3', '.m4a', '.wav', '.webm', '.ogg', '.flac']

    # File size limits
    MAX_AUDIO_FILE_SIZE_MB = 25  # 25 MB max
    MAX_AUDIO_FILE_SIZE_BYTES = MAX_AUDIO_FILE_SIZE_MB * 1024 * 1024

    # Duration limits
    MIN_AUDIO_DURATION_SECONDS = 0.1  # 100ms min
    MAX_AUDIO_DURATION_SECONDS = 300  # 5 minutes max

    # Processing
    AUDIO_SAMPLE_RATE = 16000  # 16 kHz (Whisper requirement)
    AUDIO_CHANNELS = 1  # Mono

    # Storage
    AUDIO_TEMP_DIR = "temp/audio"
    AUDIO_RETENTION_MINUTES = 60  # Delete after 1 hour
```

### Validation Service

Implement comprehensive audio validation before accepting files for processing. Check file format, duration, file size, and basic integrity. Reject invalid files early with clear error messages to save processing resources.

```python
# app/services/audio_validation_service.py
import os
from pydub import AudioSegment
from typing import Tuple

class AudioValidationService:
    """Validate audio files"""

    @staticmethod
    def validate_audio_file(
        file_path: str,
        file_size: int,
        content_type: str
    ) -> Tuple[bool, str]:
        """Validate audio file"""

        # Check content type
        if content_type not in AudioSettings.ACCEPTED_AUDIO_FORMATS:
            return False, f"Unsupported format: {content_type}"

        # Check file extension
        ext = os.path.splitext(file_path)[1].lower()
        if ext not in AudioSettings.ACCEPTED_FILE_EXTENSIONS:
            return False, f"Unsupported extension: {ext}"

        # Check file size
        if file_size > AudioSettings.MAX_AUDIO_FILE_SIZE_BYTES:
            max_mb = AudioSettings.MAX_AUDIO_FILE_SIZE_MB
            return False, f"File too large (max: {max_mb} MB)"

        # Load audio and check duration
        try:
            audio = AudioSegment.from_file(file_path)
            duration_seconds = len(audio) / 1000.0

            if duration_seconds < AudioSettings.MIN_AUDIO_DURATION_SECONDS:
                return False, "Audio too short"

            if duration_seconds > AudioSettings.MAX_AUDIO_DURATION_SECONDS:
                max_min = AudioSettings.MAX_AUDIO_DURATION_SECONDS / 60
                return False, f"Audio too long (max: {max_min} minutes)"

            logger.info(f"Audio validated: {duration_seconds:.2f}s, {file_size} bytes")
            return True, "Valid"

        except Exception as e:
            logger.error(f"Audio validation error: {e}")
            return False, f"Invalid audio file: {str(e)}"
```

## ⚡ Async Audio Processing Rules

Audio transcription and synthesis are slow operations that must run asynchronously to avoid blocking HTTP requests. Use background tasks or queues (Celery, Redis Queue) for processing. Return job IDs immediately and provide status polling or webhooks for completion notifications.

### Async STT Processing

```python
# app/services/speech_to_text_service.py
from openai import AsyncOpenAI
import asyncio

class SpeechToTextService:
    """Async speech-to-text using Whisper"""

    def __init__(self):
        self.client = AsyncOpenAI(api_key=settings.OPENAI_API_KEY)
        self.model = "whisper-1"

    async def transcribe_audio(
        self,
        audio_file_path: str,
        language: str = None
    ) -> dict:
        """
        Transcribe audio file to text asynchronously.

        Args:
            audio_file_path: Path to audio file
            language: Optional language hint (ISO-639-1 code: 'en', 'si', 'ta')

        Returns:
            dict: Transcription result with text and metadata
        """

        logger.info(f"Transcribing audio: {audio_file_path}")
        start_time = asyncio.get_event_loop().time()

        try:
            # Open file in async context
            async with asyncio.to_thread(open, audio_file_path, 'rb') as audio_file:
                response = await self.client.audio.transcriptions.create(
                    model=self.model,
                    file=audio_file,
                    language=language,
                    response_format="verbose_json"
                )

            processing_time = asyncio.get_event_loop().time() - start_time

            logger.info(f"Transcription completed in {processing_time:.2f}s")

            return {
                "text": response.text,
                "language": response.language,
                "duration": response.duration,
                "processing_time": processing_time,
                "model": self.model
            }

        except Exception as e:
            logger.error(f"Transcription failed: {e}")
            raise VoiceProcessingException(f"Speech-to-text failed: {str(e)}")
```

### Async TTS Processing

Text-to-speech synthesis also requires async processing, especially for longer responses. Queue TTS jobs and return streaming URLs or job IDs. Cache synthesized audio to avoid regenerating identical responses.

```python
# app/services/text_to_speech_service.py

class TextToSpeechService:
    """Async text-to-speech"""

    def __init__(self):
        self.client = AsyncOpenAI(api_key=settings.OPENAI_API_KEY)

    async def synthesize_speech(
        self,
        text: str,
        language: str = "English",
        voice: str = "alloy"
    ) -> str:
        """
        Convert text to speech asynchronously.

        Args:
            text: Text to synthesize
            language: Language of text
            voice: Voice ID (alloy, echo, fable, onyx, nova, shimmer)

        Returns:
            str: Path to generated audio file
        """

        if not text or len(text.strip()) == 0:
            raise ValueError("Text cannot be empty")

        if len(text) > 4096:
            raise ValueError("Text too long (max: 4096 characters)")

        logger.info(f"Synthesizing speech: {len(text)} chars, voice={voice}")

        try:
            response = await self.client.audio.speech.create(
                model="tts-1",
                voice=voice,
                input=text,
                response_format="mp3"
            )

            # Save to temporary file
            output_path = await self._save_audio_stream(response)

            logger.info(f"Speech synthesized: {output_path}")
            return output_path

        except Exception as e:
            logger.error(f"TTS failed: {e}")
            raise VoiceProcessingException(f"Text-to-speech failed: {str(e)}")

    async def _save_audio_stream(self, response) -> str:
        """Save audio stream to temporary file"""

        output_dir = AudioSettings.AUDIO_TEMP_DIR
        os.makedirs(output_dir, exist_ok=True)

        filename = f"tts_{uuid.uuid4()}.mp3"
        output_path = os.path.join(output_dir, filename)

        async with asyncio.to_thread(open, output_path, 'wb') as f:
            async for chunk in response.iter_bytes():
                await asyncio.to_thread(f.write, chunk)

        return output_path
```

## 💾 Temporary Storage & Auto-Deletion

Audio files consume significant storage and should be treated as temporary data. Store files locally or in object storage with automatic expiration policies. Implement cleanup jobs to delete processed files after a retention period (24-48 hours). Never accumulate audio files indefinitely.

### File Storage Manager

```python
# app/services/temp_file_manager.py
import os
import time
from datetime import datetime, timedelta
from pathlib import Path

class TempFileManager:
    """Manage temporary audio files"""

    @staticmethod
    def save_uploaded_audio(
        file_content: bytes,
        original_filename: str
    ) -> str:
        """Save uploaded audio to temporary location"""

        # Create temp directory
        temp_dir = AudioSettings.AUDIO_TEMP_DIR
        os.makedirs(temp_dir, exist_ok=True)

        # Generate unique filename
        timestamp = datetime.utcnow().strftime("%Y%m%d_%H%M%S")
        ext = os.path.splitext(original_filename)[1]
        filename = f"upload_{timestamp}_{uuid.uuid4()}{ext}"

        file_path = os.path.join(temp_dir, filename)

        # Write file
        with open(file_path, 'wb') as f:
            f.write(file_content)

        logger.info(f"Audio saved: {file_path}")

        # Schedule deletion
        TempFileManager.schedule_deletion(file_path)

        return file_path

    @staticmethod
    def schedule_deletion(file_path: str):
        """Schedule file deletion after retention period"""

        retention_minutes = AudioSettings.AUDIO_RETENTION_MINUTES
        deletion_time = datetime.utcnow() + timedelta(minutes=retention_minutes)

        # Add to deletion queue (could use APScheduler or background task)
        logger.info(f"File scheduled for deletion at {deletion_time}: {file_path}")

        # For immediate implementation, use background task
        import asyncio
        asyncio.create_task(
            TempFileManager._delete_after_delay(file_path, retention_minutes * 60)
        )

    @staticmethod
    async def _delete_after_delay(file_path: str, seconds: int):
        """Delete file after delay"""
        await asyncio.sleep(seconds)

        try:
            if os.path.exists(file_path):
                os.remove(file_path)
                logger.info(f"Temporary file deleted: {file_path}")
        except Exception as e:
            logger.error(f"Failed to delete temporary file {file_path}: {e}")

    @staticmethod
    def cleanup_old_files():
        """Delete files older than retention period (scheduled job)"""

        temp_dir = AudioSettings.AUDIO_TEMP_DIR

        if not os.path.exists(temp_dir):
            return

        retention_seconds = AudioSettings.AUDIO_RETENTION_MINUTES * 60
        cutoff_time = time.time() - retention_seconds

        deleted_count = 0

        for filename in os.listdir(temp_dir):
            file_path = os.path.join(temp_dir, filename)

            if os.path.isfile(file_path):
                file_age = time.time() - os.path.getmtime(file_path)

                if file_age > retention_seconds:
                    try:
                        os.remove(file_path)
                        deleted_count += 1
                        logger.debug(f"Deleted old file: {file_path}")
                    except Exception as e:
                        logger.error(f"Failed to delete {file_path}: {e}")

        logger.info(f"Cleanup complete: {deleted_count} files deleted")
```

### Scheduled Cleanup Task

Implement scheduled jobs to clean up expired audio files. Run cleanup during low-traffic periods and log all deletions for auditing. Use file age and metadata to determine what to delete.

```python

from apscheduler.schedulers.asyncio import AsyncIOScheduler

def schedule_audio_cleanup():

    # Run every hour

        hours=1
```

## 🔧 Whisper Error Handling

Whisper (OpenAI's STT model) can fail due to network issues, rate limits, or audio quality problems. Implement robust error handling with specific handling for different error types. Use retries with exponential backoff for transient failures and provide meaningful error messages for permanent failures.

### Error Types & Handling

```python
# app/core/exceptions.py

class VoiceProcessingException(BaseAPIException):
    """Voice processing errors"""
    def __init__(self, detail: str):
        super().__init__(detail=detail, status_code=422)

class AudioTooLongException(VoiceProcessingException):
    def __init__(self):
        super().__init__("Audio file is too long (max: 5 minutes)")

class AudioTooShortException(VoiceProcessingException):
    def __init__(self):
```

### Resilient Transcription

Wrap Whisper API calls with retry logic and proper error classification. Handle rate limits gracefully with exponential backoff. Log all failures for monitoring and provide fallback behavior when transcription is unavailable.

```python
async def transcribe_with_retry(
    self,
    audio_file_path: str,
    max_retries: int = 3
) -> dict:
    """Transcribe with retry logic"""

    last_error = None

    for attempt in range(1, max_retries + 1):
        try:
            logger.info(f"Transcription attempt {attempt}/{max_retries}")

            result = await self.transcribe_audio(audio_file_path)
            return result

        except Exception as e:
            last_error = e
            logger.warning(f"Attempt {attempt} failed: {e}")

            if attempt < max_retries:
                # Exponential backoff
                wait_time = 2 ** attempt
                logger.info(f"Retrying in {wait_time}s...")
                await asyncio.sleep(wait_time)

    # All retries failed
    logger.error(f"Transcription failed after {max_retries} attempts")
    raise VoiceProcessingException(f"Transcription failed: {str(last_error)}")
```

## 🔀 Voice → Text Normalization

Raw transcriptions from speech-to-text engines contain artifacts, filler words, and inconsistent formatting. Apply normalization to clean up transcriptions before using them as queries. Remove filler words ("um", "uh"), normalize punctuation, and fix common speech-to-text errors.

### Post-Processing Transcriptions

```python
# app/services/transcription_normalizer.py

class TranscriptionNormalizer:
    """Normalize transcribed text"""

    @staticmethod
    def normalize(text: str, language: str) -> str:
        """Normalize transcribed text"""

        # Remove extra whitespace
        text = ' '.join(text.split())

        # Fix common Whisper artifacts
        text = TranscriptionNormalizer._fix_whisper_artifacts(text)

        # Language-specific normalization
        if language == "English":
            text = TranscriptionNormalizer._normalize_english(text)
        elif language in ["Sinhala", "Tamil"]:
            text = TranscriptionNormalizer._normalize_indic(text)

        return text.strip()

    @staticmethod
    def _fix_whisper_artifacts(text: str) -> str:
        """Fix common Whisper transcription issues"""

        # Remove [BLANK_AUDIO] markers
        text = text.replace('[BLANK_AUDIO]', '')

        # Remove excessive repetition (stuttering)
        words = text.split()
        deduplicated = []
        prev_word = None
        repeat_count = 0

        for word in words:
            if word == prev_word:
                repeat_count += 1
                if repeat_count < 2:  # Allow one repetition
                    deduplicated.append(word)
            else:
                deduplicated.append(word)
                repeat_count = 0

            prev_word = word

        return ' '.join(deduplicated)

    @staticmethod
    def _normalize_english(text: str) -> str:
        """English-specific normalization"""

        # Capitalize sentences
        sentences = text.split('. ')
        capitalized = [s.capitalize() for s in sentences]
        return '. '.join(capitalized)

    @staticmethod
    def _normalize_indic(text: str) -> str:
        """Sinhala/Tamil normalization"""

        # Unicode normalization
        import unicodedata
        return unicodedata.normalize('NFC', text)
```

## 🎭 TTS Provider Abstraction

Abstract TTS provider implementations behind a common interface to enable switching between providers (OpenAI, Google, AWS Polly) without changing application code. This provides flexibility for cost optimization, multi-language support, and fallback strategies.

### Provider Interface

```python
# app/services/tts/base_provider.py
from abc import ABC, abstractmethod

class TTSProvider(ABC):
    """Base class for TTS providers"""

    @abstractmethod
    async def synthesize(
        self,
        text: str,
        language: str,
        voice: str
    ) -> str:
        """Generate speech from text"""
        pass

    @abstractmethod
    def get_available_voices(self, language: str) -> list:
        """Get available voices for language"""
        pass
```

### OpenAI TTS Provider

Implement the TTS interface for OpenAI's text-to-speech API. Support voice selection and audio format configuration. Handle API errors and rate limits appropriately.

```python
# app/services/tts/openai_provider.py

class OpenAITTSProvider(TTSProvider):
    """OpenAI TTS implementation"""

    VOICES = {
        "English": ["alloy", "echo", "fable", "onyx", "nova", "shimmer"],
        "Sinhala": ["alloy", "nova"],  # Limited support
        "Tamil": ["alloy", "nova"]
    }

    async def synthesize(self, text: str, language: str, voice: str) -> str:
        """Generate speech using OpenAI TTS"""

        client = AsyncOpenAI(api_key=settings.OPENAI_API_KEY)

        response = await client.audio.speech.create(
            model="tts-1",
            voice=voice,
            input=text
        )

        return await self._save_audio(response)

    def get_available_voices(self, language: str) -> list:
        return self.VOICES.get(language, self.VOICES["English"])
```

### Google TTS Provider

Implement the TTS interface for Google Cloud Text-to-Speech. Google provides better multilingual support and more voice options, which may be useful for Sinhala and Tamil synthesis.

```python
# app/services/tts/google_provider.py
from google.cloud import texttospeech

class GoogleTTSProvider(TTSProvider):
    """Google Cloud TTS implementation"""

    def __init__(self):
        self.client = texttospeech.TextToSpeechClient()

    async def synthesize(self, text: str, language: str, voice: str) -> str:
        """Generate speech using Google Cloud TTS"""

        # Language codes
        language_codes = {
            "English": "en-US",
            "Sinhala": "si-LK",
            "Tamil": "ta-IN"
        }

        synthesis_input = texttospeech.SynthesisInput(text=text)

        voice_params = texttospeech.VoiceSelectionParams(
            language_code=language_codes.get(language, "en-US"),
            name=voice
        )

        audio_config = texttospeech.AudioConfig(
            audio_encoding=texttospeech.AudioEncoding.MP3
        )

        response = await asyncio.to_thread(
            self.client.synthesize_speech,
            input=synthesis_input,
            voice=voice_params,
            audio_config=audio_config
        )

        return await self._save_audio_bytes(response.audio_content)

    def get_available_voices(self, language: str) -> list:
        # Query Google Cloud for available voices
        pass
```

### Provider Factory

Use a factory pattern to instantiate the appropriate TTS provider based on configuration. This enables runtime switching between providers and A/B testing of different TTS engines.

```python
# app/services/tts/tts_factory.py

class TTSFactory:
    """Factory for TTS providers"""

    _providers = {
        "openai": OpenAITTSProvider,
        "google": GoogleTTSProvider,
        "aws": AWSPollyProvider
    }

    @classmethod
    def get_provider(cls, provider_name: str = None) -> TTSProvider:
        """Get TTS provider instance"""

        provider_name = provider_name or settings.TTS_PROVIDER

        if provider_name not in cls._providers:
            raise ValueError(f"Unknown TTS provider: {provider_name}")

        return cls._providers[provider_name]()
```

## 🚨 Common Mistakes to Avoid

❌ **Synchronous file operations**

```python
# BAD
with open(file_path, 'rb') as f:
    data = f.read()  # Blocks event loop!
```

❌ **No file cleanup**

```python
# BAD
save_audio(file)  # File never deleted
```

❌ **No validation**

```python
# BAD
transcribe(audio_file)  # No format/size check!
```

❌ **Hardcoded provider**

```python
# BAD
client = OpenAI()  # Can't switch providers
```
