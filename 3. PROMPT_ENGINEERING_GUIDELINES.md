# 2️⃣ Prompt Engineering & Management Guidelines

## 📋 Purpose

Ensure **consistent**, **safe**, and **testable** prompts for the OpenJustice legal assistance platform. Prevent prompt injection, maintain neutrality, and support multilingual operations.

---

## 🎯 Core Principles

1. **Template-Based** - No hardcoded prompt strings
2. **Version Controlled** - Track all prompt changes
3. **Structured Inputs** - No raw string concatenation
4. **Injection-Safe** - Validate and sanitize all inputs
5. **Neutral Language** - No bias or legal advice

### Prompt Registry Pattern

Implement a registry pattern to centralize prompt management. This allows dynamic version selection, easy A/B testing, and maintains a single source of truth for all prompt templates. The registry should support versioning and provide fallback to latest versions.

```python
# app/prompts/__init__.py
"""Centralized prompt template registry"""

from typing import Dict, Optional
from enum import Enum

class PromptType(Enum):
    LEGAL_ASSISTANT = "legal_assistant"
    SUMMARIZATION = "summarization"
    TRANSLATION = "translation"
    CITATION_EXTRACTION = "citation_extraction"

class PromptRegistry:
    """Manage all prompt templates"""

    _templates: Dict[str, Dict[str, str]] = {}

    @classmethod
    def register(cls, name: str, version: str, template: str):
        """Register a prompt template"""
        if name not in cls._templates:
            cls._templates[name] = {}
        cls._templates[name][version] = template

    @classmethod
    def get(cls, name: str, version: str = "latest") -> str:
        """Get prompt template by name and version"""
        if name not in cls._templates:
            raise ValueError(f"Unknown prompt template: {name}")

        templates = cls._templates[name]

        if version == "latest":
            # Get highest version
            version = max(templates.keys())

        if version not in templates:
            raise ValueError(f"Version {version} not found for {name}")

        return templates[version]

    @classmethod
    def list_versions(cls, name: str) -> list:
        """List all versions of a template"""
        return list(cls._templates.get(name, {}).keys())

# Convenience function
def get_prompt(name: str, version: str = "latest") -> str:
    """Get prompt template"""
    return PromptRegistry.get(name, version)
```

## 🏗️ Structured Input System

Avoid string concatenation when building prompts. Use structured templates with named parameters for clarity, maintainability, and security. Structured inputs make it easier to validate data, prevent injection attacks, and track changes over time.

### ❌ WRONG: String Concatenation

```python
# DON'T DO THIS!
def build_prompt(query: str, context: str):
    prompt = "You are a legal assistant. "
    prompt += "Here is the context: " + context
    prompt += "\nUser question: " + query
    return prompt
```

### ✅ CORRECT: Template-Based Approach

```python
# app/prompts/legal_assistant.py
from app.prompts import PromptRegistry

LEGAL_ASSISTANT_SYSTEM_V1 = """You are a legal information assistant for Sri Lankan law.

MANDATORY RULES:
1. Only answer questions about Sri Lankan law
2. Always cite sources: [Source: {source_format}]
3. Respond in the user's language: {language}
4. If uncertain, state: "I don't have enough information to answer this question."
5. Never provide legal advice - only legal information
6. Maintain neutral, professional tone

CONTEXT:
{context}

RESPONSE FORMAT:
- Clear, concise answer
- Citations after each fact
- Confidence level at end: [Confidence: High/Medium/Low]
"""

# Register template
PromptRegistry.register(
    name="legal_assistant_system",
    version="v1",
    template=LEGAL_ASSISTANT_SYSTEM_V1
)

class LegalPromptBuilder:
    """Build structured legal prompts"""

    @staticmethod
    def build_legal_query_prompt(
        query: str,
        context: str,
        language: str = "English",
        source_format: str = "Act Name, Section X"
    ) -> dict:
        """Build prompt with validation"""

        # Validate inputs
        if not query or len(query.strip()) == 0:
            raise ValueError("Query cannot be empty")

        if len(query) > 1000:
            raise ValueError("Query too long (max 1000 chars)")

        # Get template
        system_template = get_prompt("legal_assistant_system", "v1")

        # Format with structured data
        system_message = system_template.format(
            context=context[:4000],  # Truncate if needed
            language=language,
            source_format=source_format
        )

        return {
            "system": system_message,
            "user": query,
            "metadata": {
                "template": "legal_assistant_system",
                "version": "v1",
                "language": language
            }
        }
```

### Using Pydantic for Input Validation

Use Pydantic models to validate all prompt inputs before they reach the LLM. This catches malformed data early, enforces length limits, and provides automatic sanitization. Pydantic validators can also detect injection patterns before prompts are constructed.

```python
# app/schemas/prompt.py
from pydantic import BaseModel, Field, validator
from typing import Literal

class LegalQueryInput(BaseModel):
    """Validated input for legal queries"""

    query: str = Field(..., min_length=3, max_length=1000)
    context: str = Field(..., max_length=10000)
    language: Literal["English", "Sinhala", "Tamil"] = "English"
    temperature: float = Field(0.3, ge=0.0, le=1.0)

    @validator('query')
    def validate_query(cls, v):
        """Sanitize query input"""
        # Remove control characters
        v = ''.join(char for char in v if char.isprintable() or char.isspace())

        # Check for prompt injection patterns
        forbidden_patterns = [
            "ignore previous instructions",
            "ignore all previous",
            "disregard above",
            "new instructions:",
            "system:",
            "assistant:"
        ]

        v_lower = v.lower()
        for pattern in forbidden_patterns:
            if pattern in v_lower:
                raise ValueError(f"Query contains forbidden pattern: {pattern}")

        return v.strip()

    @validator('context')
    def validate_context(cls, v):
        """Ensure context is from trusted sources"""
        if not v or len(v.strip()) == 0:
            raise ValueError("Context cannot be empty")
        return v
```

## ⚖️ Neutral Legal Language Rules

Legal information systems must use neutral, factual language without bias or personal opinions. Avoid phrases that suggest legal advice ("you should", "I recommend") and emotional language. Maintain clear distinction between stating what the law says versus offering interpretations or recommendations.

### Language Standards

```python
# app/prompts/language_standards.py

PROHIBITED_PHRASES = [
    # Legal advice (we only provide information)
    "you should",
    "you must",
    "I recommend",
    "my advice is",

    # Definitive judgments
    "definitely",
    "certainly will",
    "guaranteed",

    # Biased language
    "obviously",
    "clearly wrong",
    "ridiculous",

    # Emotional language
    "unfortunately",
    "sadly",
    "happily"
]

PREFERRED_PHRASES = {
    "you should": "the law states",
    "I recommend": "legal provisions indicate",
    "definitely": "according to [source]",
    "my advice is": "the legal framework suggests"
}

NEUTRAL_LANGUAGE_PROMPT_ADDITION = """
LANGUAGE REQUIREMENTS:
- Use neutral, factual language only
- Avoid: "you should", "I recommend", "definitely"
- Use: "the law states", "according to", "legal provisions indicate"
- Differentiate between law and interpretation
- Never provide personal opinions
"""
```

### Response Validation

Automatically validate LLM responses for neutral language compliance. Check for prohibited phrases, advice indicators, and biased language. Assign scores to responses and reject those that don't meet neutrality thresholds.

```python
def validate_neutral_language(response: str) -> dict:
    """Check if response maintains neutral language"""

    violations = []

    # Check for prohibited phrases
    response_lower = response.lower()
    for phrase in PROHIBITED_PHRASES:
        if phrase in response_lower:
            violations.append({
                "type": "prohibited_phrase",
                "phrase": phrase,
                "suggestion": PREFERRED_PHRASES.get(phrase, "Rephrase neutrally")
            })

    # Check for advice indicators
    advice_patterns = [
        r'\b(should|must|need to|have to)\b',
        r'\b(recommend|advise|suggest)\b',
        r'\b(definitely|certainly|absolutely)\b'
    ]

    for pattern in advice_patterns:
        matches = re.findall(pattern, response_lower)
        if matches:
            violations.append({
                "type": "advice_indicator",
                "pattern": pattern,
                "matches": matches
            })

    return {
        "is_neutral": len(violations) == 0,
        "violations": violations,
        "score": max(0, 1.0 - (len(violations) * 0.2))
    }
```

## 🛡️ Prompt Injection Prevention

Prompt injection attacks attempt to override system instructions by inserting malicious text into user inputs. Implement multiple layers of defense including pattern detection, input sanitization, and structured template usage. Log all suspected injection attempts for security review.

### Input Sanitization

```python
# app/core/prompt_security.py
import re
from typing import Tuple

class PromptSecurityValidator:
    """Detect and prevent prompt injection attacks"""

    # Injection patterns
    INJECTION_PATTERNS = [
        r'ignore\s+(previous|above|all)',
        r'disregard\s+(previous|above|instructions)',
        r'new\s+instructions?:',
        r'system\s*:',
        r'assistant\s*:',
        r'<\|.*?\|>',  # Special tokens
        r'\[INST\].*?\[/INST\]',  # Instruction tags
        r'{{.*?}}',  # Template injection
        r'prompt\s*=',
        r'role\s*:\s*system'
    ]

    @classmethod
    def is_safe(cls, text: str) -> Tuple[bool, list]:
        """Check if text contains injection attempts"""

        violations = []
        text_lower = text.lower()

        for pattern in cls.INJECTION_PATTERNS:
            matches = re.findall(pattern, text_lower, re.IGNORECASE)
            if matches:
                violations.append({
                    "pattern": pattern,
                    "matches": matches,
                    "severity": "high"
                })

        # Check for excessive special characters
        special_char_ratio = sum(1 for c in text if not c.isalnum() and not c.isspace()) / len(text)
        if special_char_ratio > 0.3:
            violations.append({
                "type": "excessive_special_chars",
                "ratio": special_char_ratio,
                "severity": "medium"
            })

        return len(violations) == 0, violations

    @classmethod
    def sanitize(cls, text: str) -> str:
        """Remove potentially dangerous patterns"""

        # Remove control characters
        text = ''.join(char for char in text if char.isprintable() or char.isspace())

        # Remove injection patterns
        for pattern in cls.INJECTION_PATTERNS:
            text = re.sub(pattern, '', text, flags=re.IGNORECASE)

        # Normalize whitespace
        text = ' '.join(text.split())

        return text.strip()
```

### Safe Prompt Construction

Build prompts using a multi-step validation pipeline: detect injection attempts, sanitize inputs, use structured templates, and add security markers. Always validate before construction, never trust user input directly.

```python
async def build_safe_prompt(
    query: str,
    context: str,
    user_id: int
) -> dict:
    """Build prompt with security validation"""

    # Step 1: Validate query safety
    is_safe, violations = PromptSecurityValidator.is_safe(query)

    if not is_safe:
        logger.warning(f"Prompt injection attempt by user {user_id}: {violations}")
        raise SecurityException(
            "Input contains potentially unsafe content",
            details={"violations": violations}
        )

    # Step 2: Sanitize inputs
    safe_query = PromptSecurityValidator.sanitize(query)

    # Step 3: Use structured templates (not string concat)
    prompt_data = LegalPromptBuilder.build_legal_query_prompt(
        query=safe_query,
        context=context,
        language="English"
    )

    # Step 4: Add security markers (to detect prompt leakage)
    prompt_data['system'] += "\n\n[SECURITY_MARKER: OpenJustice_2025]"

    return prompt_data
```

Maintain separate prompt templates for each supported language (English, Sinhala, Tamil). Avoid translation—create native language templates that respect cultural context and legal terminology. Never mix languages within a single template.

## 🔄 Prompt Change Review Process

Treat prompt changes like code changes—require review, testing, and approval before deployment. Track version history, authors, and detailed changelogs. Never deploy prompts directly to production without A/B testing against previous versions.

### Version Control Workflow

```python
# app/prompts/versioning.py
from datetime import datetime
from typing import Optional

class PromptVersion:
    """Track prompt versions"""

    def __init__(
        self,
        name: str,
        version: str,
        content: str,
        author: str,
        changelog: str,
        approved: bool = False
    ):
        self.name = name
        self.version = version
        self.content = content
        self.author = author
        self.changelog = changelog
        self.approved = approved
        self.created_at = datetime.utcnow()

    def to_dict(self) -> dict:
        return {
            "name": self.name,
            "version": self.version,
            "content": self.content,
            "author": self.author,
            "changelog": self.changelog,
            "approved": self.approved,
            "created_at": self.created_at.isoformat()
        }

# Example usage
NEW_PROMPT_VERSION = PromptVersion(
    name="legal_assistant_system",
    version="v2",
    content=LEGAL_ASSISTANT_SYSTEM_V2,
    author="research-team",
    changelog="""
    Changes in v2:
    - Added confidence level requirement
    - Improved citation format
    - Added multilingual support
    - Enhanced neutrality guidelines
    """,
    approved=False  # Requires review
)
```

### Change Testing Protocol

A/B test new prompt versions against a suite of representative test queries. Compare citation quality, neutrality scores, and response accuracy. Document differences and require approval before rollout if significant changes are detected.

```python
async def test_prompt_change(
    old_version: str,
    new_version: str,
    test_queries: list
) -> dict:
    """Test prompt changes before deployment"""

    results = []

    for query in test_queries:
        # Generate with old version
        old_response = await generate_with_prompt(query, old_version)

        # Generate with new version
        new_response = await generate_with_prompt(query, new_version)

        # Compare results
        comparison = {
            "query": query,
            "old_response": old_response,
            "new_response": new_response,
            "citations_old": extract_citations(old_response),
            "citations_new": extract_citations(new_response),
            "neutrality_score_old": validate_neutral_language(old_response)['score'],
            "neutrality_score_new": validate_neutral_language(new_response)['score']
        }

        results.append(comparison)

    return {
        "version_old": old_version,
        "version_new": new_version,
        "test_count": len(test_queries),
        "results": results,
        "summary": generate_comparison_summary(results)
    }
```
